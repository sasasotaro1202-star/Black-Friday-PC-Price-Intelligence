# Black Friday PC Price Intelligence

2026年ブラックフライデーに向けて、自作PCの部品価格・在庫・互換性と周辺機器の購入条件を無料で監視・検証するプロジェクトです。GitHub Actionsは証拠データの継続収集、ChatGPTは依頼時点の最新情報を用いた最終分析を担当します。

## 運用原則

- GitHub Actionsは価格、在庫、型番、公式セール日程、価格履歴、取得失敗、データ品質を継続収集します。
- 自動生成のランキングや買い時判定は内部診断用です。最終順位はユーザーから依頼があった時点で、ChatGPTが最新データと必要な外部情報を再検証して作成します。
- 「BF購入目標」「セール前の参考価格」「現在の観測価格」「公式キャンペーン期間内の確認価格」「最終決済額」を明確に分けます。目標価格は値下がり予測や実売価格ではありません。
- 取得失敗は在庫切れを意味せず、型番や販売元が曖昧な価格を確定値にしません。未確認項目は未確認のまま記録します。
- ブラックフライデーで値下がりする可能性だけで買い時を決めず、価格・在庫・互換性・返品条件と総額で判断します。

## 予算と購入条件（2026-10-17更新）

- **総予算の上限：400,000円**
- **PC本体の購入計画枠：350,000円**
- **周辺機器の目標予算：45,000円**
- **未割当の総額予備費：5,000円**
- PC本体は自作方式を本命とし、組み立て時間は制約・減点にしません。BTO完成品は同等構成の価格比較用ベンチマークにとどめます。
- PCは購入時点で**メモリ32GB以上、SSD 1TB以上**。購入後の増設を前提にした基本構成は購入候補として認めません。
- 周辺機器は**メインモニター1台だけ**（AOC Q27G40E/11、27インチWQHD）。サブモニターとヘッドセットは購入しません。
- 周辺機器は福岡の実店舗購入が前提です。ビックカメラ天神1号館・ヨドバシカメラ マルチメディア博多を優先候補とします。**周辺機器の送料は計上しません**。Web価格は店舗の現金価格や支店在庫の証拠にはなりません。
- 周辺機器の45,000円は商品目標と予備枠を含みます。モニター・スピーカー・キーボード・マウス・マウスパッド・電源タップ・必要時のケーブルを組み合わせ、付属品が使える場合は不要なケーブルを買いません。

## 自作PC候補と予算試算

次は各部品のブラックフライデー購入目標を合算した計画値です。現在確認済みの完成品価格や将来の価格予測ではありません。

| 順位・役割 | CPU / GPU | PC本体の部品・送料・小物の目標 | 周辺機器45,000円込みの目標 |
|---:|---|---:|---:|
| 本命 | Ryzen 7 9700X + RTX 5070 12GB | 300,600円 | **345,600円** |
| VRAM代替 | Ryzen 7 9700X + RTX 5060 Ti 16GB | 280,600円 | **325,600円** |
| 大穴 | Ryzen 7 9700X + RTX 5070 Ti 16GB | 324,800円 | **369,800円** |

計画式にすると、PC本体300,600円、周辺機器込み345,600円です。大穴のRTX 5070 Ti 16GBは、PC本体324,800円、周辺機器込み369,800円です。すべてBF目標価格による合算で、現行実売価格ではありません。

RTX 5070 12GBをゲームと汎用用途のバランス候補、RTX 5060 Ti 16GBをVRAM容量を重視する代替、RTX 5070 Ti 16GBを大穴として、いずれも比較ランキングに残します。総額上限40万円は目標最適化の基準であり、順位付けから大穴を削除する絶対条件ではありません。購入許可は型番一致の販売価格、在庫、部品互換性、送料を含む総額を確認してから判断します。

主な互換性保留事項：
- ASRock B850M Pro RS WiFiのRyzen 7 9700X対応に必要なBIOSは3.12ですが、実際に出荷されるBIOSバージョンは未確認です。
- TeamGroup T-CREATE EXPERT DDR5-6000 32GBキットと当該マザーボードの正確なQVL掲載は未確認です。
- RTX 5070 Tiの候補は約2.98スロット厚のため、ケース・電源ケーブルのクリアランスを購入する正確な型番で再確認します。
- CPU・GPU・RAM・SSDの目標価格は希望値であり、検証済み実売とは異なります。

構成の詳細：[自作PC部品表と組み立てガイド](docs/self-build-assembly-guide.md)

## 値上がりリスクの監視方針

- **優先1：GPU。** 国内RTX 50シリーズ価格の国際比較差とモデル別の在庫・実売の変化を監視。ただし海外価格との差は将来値上がりの確定証拠ではありません。
- **優先2：CPU。** 秋葉原の2026年10月前半価格調査でRyzen 7 9700Xは51,800円（前回調査比+29.6%）、9800X3Dは74,800円（+24.7%）と報告されました。これは調査時点の国内価格変化であり、全販売店の価格を示すものではありません。
- **優先3：DDR5メモリ。** TrendForceは2026年第4四半期の従来型DRAM契約価格を前期比+10〜15%と予測しています。個別メモリキットの店頭価格が同率で上がるという意味ではありません。
- **優先4：SSD/NAND。** TrendForceは同四半期のNAND契約価格を+15〜20%と予測していますが、個別消費者向けSSDの実売は製品や販売店で異なります。
- マザーボード、電源、ケース、冷却、周辺機器は、一般論だけで一律の値上がりを断定せず、型番別の価格・在庫変化で判断します。

詳細なルールと出典：[値上がりリスク判定プレイブック](docs/price-rise-risk-playbook.md)

## セール日程・監視間隔

- 各店の2026年ブラックフライデー公式開催日程は、年付きの日付範囲を公式ページで確認するまで未確定です。
- 暫定の広域監視窓は `2026-11-01 00:00 JST`〜`2026-12-11 23:59 JST` です。これは価格を集めるための監視窓であり、**公式開催日程ではありません**。11月14日などの特定日をすべての店の開始日とは扱いません。
- 通常期間は約15分ごと、暫定の広域監視窓では約5分ごとに観測する設定です。正確な実行状況は [GitHub Actions](https://github.com/sasasotaro1202-star/Black-Friday-PC-Price-Intelligence/actions) を確認します。
- 監視期間内の価格でも、販売元の2026年公式キャンペーン期間、正確な商品型番、在庫、適用条件、取得時刻（PIT）が揃っていなければ「BF期間内の確認済み価格」として採用しません。

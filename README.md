# Black Friday PC Price Intelligence

2026年ブラックフライデー期間を通じ、日本国内で購入できるPCと周辺機器の実売価格・在庫・構成・過去セール根拠を監視し、総予算40万円に収まる購入候補を評価する無料運用のプロジェクトです。

## 購入条件（2026-10-12更新）

- 総予算：**400,000円（PC本体＋周辺機器）**
- 周辺機器の目標予算：**69,800円**（27型WQHDメイン＋23.8型FHD IPS 100Hzサブ＋音質・機能・価格のバランスを取ったEDIFIER MR4 MKIIスピーカーを含む）
- PC本体の目標価格：**330,200円**
- PC本体の計画上限：**330,200円**。周辺機器が目標予算内に収まる場合のみ。実売が目標を超えた場合は動的上限を引き下げる。
- PC本体の必須構成：**メモリ32GB以上、SSD 1TB以上**。
- デスクトップ優先。ただし、条件を満たすノートPCや超特価も監視対象から外さない。
- **モニターは2台**（27型WQHDメイン＋23.8型FHD IPS 100Hzサブ）。ヘッドセットは購入対象外。
- **主予算の周辺機器：** AOC Q27G40E/11 メインモニター＋LG 24MS500-B サブモニター＋EDIFIER MR4 MKII＋Logicool G213r＋Logicool G304＋SteelSeries QcK Large。各カテゴリの順位・代替候補・画像確認用の商品ページは [docs/peripheral-rankings.md](docs/peripheral-rankings.md) にまとめる。代替候補は同時購入せず、カテゴリから1商品だけ選ぶ。
- スピーカーは**EDIFIER MR4 MKII**を採用し、BF購入目標は24,000円。公式仕様は合計80W RMS、50Hz–40kHz、Bluetooth 6.0マルチポイント、XLR/TRS/RCA/AUX/Bluetooth入力、専用アプリに対応。公式掲載額29,980円はBF前の参考値。公式ページに表示される20%クーポンは決済画面での適用と最終現金支払額を確認するまで控除せず、BF期間まで有効と仮定しない。
- 周辺機器、送料、必須費用を含めて総額判定を行う。クーポン・ポイント・抽選特典は条件と決済額が確認できるまで現金値引きとして扱わない。

## 周辺機器カテゴリ別ランキング

メインモニター、サブモニター、スピーカー、キーボード、マウス、マウスパッド、電源タップ、ケーブルをカテゴリ別に順位付けした購入ガイドは [docs/peripheral-rankings.md](docs/peripheral-rankings.md) に分離しています。各順位は「カテゴリから1商品を選ぶ」ための比較であり、全候補を同時購入するリストではありません。周辺機器の合計BF目標は¥69,800、PC本体の計画上限は¥330,200です。

## 予算の単一の正本

config/targets.json が唯一の予算設定です。budget_jpy は互換性を保つためのPC本体目標価格であり、総予算ではありません。

PC本体の上限は、周辺機器の実売価格がモデル一致済み・在庫確認済みで得られた場合に動的に再計算します。価格や在庫が未確認なら目標価格で計画額を仮計算しますが、全体購入許可は保留します。

RAM 32GB または SSD 1TBに満たない基本構成は NEEDS_CONFIGURATION とし、購入時の構成変更を含む価格が確認されるまで購入候補としての購入許可を出しません。

## 周辺機器の別系統監視

PC候補のランキングにモニター・スピーカー・マウス等を混ぜず、scripts/peripheral_monitor.py で別々に取得・記録します。価格観測は data/peripheral_prices.json、価格/在庫イベントは data/peripheral_change_events.jsonl に保存します。実売価格は商品ページのモデル一致・妥当な価格範囲・許可ホストを検証した場合のみ有効です。取得失敗は売り切れとは扱いません。

## ランキング

100点は購入優先度であって、値下げ確率や勝率ではありません。

- 性能：40点
- 価格価値：20点
- 過去セール根拠：15点
- 在庫・売り切れリスク：15点
- 購入タイミング：10点

構成不一致、参照価格、異常価格、古い観測、在庫不明、PIT不明などは安全側に処理します。購入リンクは実在する商品URLのみを出力します。大穴・アウトレットは監視しますが、根拠の弱い値段を現行価格とみなしません。

## ゲーム適性と完成PCの選定基準

FPS・Cities: Skylines IIの快適度、RTX 5070とRTX 5060 Ti 16GBの選び分け、AI・大規模予測プログラム向けの構成、動的予算上限をまとめた [ゲーム適性・完成PCガイド](docs/game-compatibility-and-build-targets.md) を追加しています。ここでの性能評価は実測FPSの保証ではなく、公式要件と構成クラスに基づく目安です。

## GitHub Actions

- 通常時：実データ取得は約15分ごと。
- 2026年ブラックフライデー監視窓：実データ取得は約5分ごと。
- 広域監視窓：2026-11-14 00:00 JST ～ 2026-12-04 23:59 JST（各社の公式日程が確認できたら更新）。
- メイン監視ワークフローだけが定時起動を担当。高速ワークフローは手動起動専用とし、二重実行を避ける。
- Python標準ライブラリとGitHub Actions中心で無料運用。有料APIを必須にしない。

処理順序：monitor → peripheral_monitor → recover → sanitize → report → timing → scenario → healthcheck → validate → commit/push。

## 主な出力

- data/current_latest.json：PCの現行価格・在庫・処理率。
- data/peripheral_prices.json：周辺機器のモデル一致済み価格と在庫。
- data/change_events.jsonl：PC価格・在庫の変化履歴。
- data/peripheral_change_events.jsonl：周辺機器の価格・在庫の変化履歴。
- data/decision_rankings.json：100点ランキング、予算・購入ゲート、元観測スナップショットSHA256。
- data/scenario_analysis.json：PC目標価格に対する割引シナリオ（確率ではない）。
- data/timing_analysis.json：価格変更時刻の分析。
- data/buy_now_decision.json：セール全期間の「今買う／値下げ待ち／確認待ち」判定、期間内の観測最低価格、在庫・PIT・完成構成・予算ゲート、購入リンク。
- data/reports/buy-now-now.md：スマホで確認しやすい最新の買い時レポート。通常時はBF前の参考価格と区別し、BF期間中は更新ごとに候補を再評価。
- data/reports/latest.md：総予算、周辺機器の価格確認、候補ランキング、購入リンクに加えて「今この瞬間の買い時判定」を表示。

## 取得失敗の診断と検索フォールバック

直接商品ページの取得に失敗した場合、無料の検索HTMLソースを順に試します。ただし検索結果のタイトル/抜粋にカタログ登録済みSKU・型番別名が含まれる場合のみ価格候補に採用し、販売ページのSKU一致、価格妥当性、在庫、PITの検証は省略しません。ホスト別・原因別の取得エラー、検索試行、採用、SKU不一致除外件数をレポートに出力します。取得失敗は売り切れとは扱いません。

## Fail-closed方針

取得失敗は売り切れではありません。表示価格・参照価格・値引き額・クーポン・ポイントを混同しません。価格・在庫・PCの完成構成・予算内総額のいずれかが不明な場合、ランキング上の監視は続けても全体購入許可は出しません。

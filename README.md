# Black Friday PC Price Intelligence

2026年ブラックフライデー期間を通じ、自作PCの個別部品価格・互換性・周辺機器価格を監視し、総予算40万円で組める構成を評価する無料運用のプロジェクトです。BTO完成品・ノートPCは価格比較用の参考枠に残します。

## 購入条件（2026-10-12更新）

- 総予算：**400,000円（PC本体＋周辺機器）**
- 周辺機器の目標予算：**69,800円**（27型WQHDメイン＋23.8型FHD IPS 100Hzサブ＋音質・機能・価格のバランスを取ったEDIFIER MR4 MKIIスピーカーを含む）
- PC本体の目標価格：**330,200円**
- PC本体の計画上限：**330,200円**。周辺機器が目標予算内に収まる場合のみ。実売が目標を超えた場合は動的上限を引き下げる。
- PC本体の必須構成：**メモリ32GB以上、SSD 1TB以上**。
- PC本体は自作方式を第一選択。BTO完成品・ノートPCは価格比較用の参考枠とし、自作構成ランキングには混ぜません。
- **モニターは2台**（27型WQHDメイン＋23.8型FHD IPS 100Hzサブ）。ヘッドセットは購入対象外。
- **主予算の周辺機器：** AOC Q27G40E/11 メインモニター＋LG 24MS500-B サブモニター＋EDIFIER MR4 MKII＋Logicool G213r＋Logicool G304＋SteelSeries QcK Large。各カテゴリの順位・代替候補・画像確認用の商品ページは [docs/peripheral-rankings.md](docs/peripheral-rankings.md) にまとめる。代替候補は同時購入せず、カテゴリから1商品だけ選ぶ。
- スピーカーは**EDIFIER MR4 MKII**を採用し、BF購入目標は24,000円。公式仕様は合計80W RMS、50Hz–40kHz、Bluetooth 6.0マルチポイント、XLR/TRS/RCA/AUX/Bluetooth入力、専用アプリに対応。公式掲載額29,980円はBF前の参考値。公式ページに表示される20%クーポンは決済画面での適用と最終現金支払額を確認するまで控除せず、BF期間まで有効と仮定しない。
- 周辺機器、送料、必須費用を含めて総額判定を行う。クーポン・ポイント・抽選特典は条件と決済額が確認できるまで現金値引きとして扱わない。

## 自作PC本体の購入優先方針（価格はすべてBF購入目標）

- **本命：自作 Ryzen 7 9700X + RTX 5070 12GB。** B850 MicroATX、DDR5-6000 32GB（16GB×2）、NVMe SSD 1TB、850W ATX 3.1 Gold電源、エアフローケース、AM5対応空冷、Windows 11 Homeライセンスを個別に組み合わせます。部品目標小計＋送料・小物予備費でPC本体320,360円、周辺機器込み390,160円を目標とします。
- **VRAM重視の代替：RTX 5060 Ti 16GB。** 目標はPC本体295,360円、周辺機器込み365,160円。ローカルAIでVRAM容量を重視する選択肢ですが、カード寸法・補助電源が未検証のため互換性レビューが必要です。
- **大穴：RTX 5070 Ti 16GB。** 目標はPC本体329,360円、周辺機器込み399,160円。PC本体予算330,200円まで余裕840円のため、価格差や追加費用で予算超過し得ます。正確な型番・寸法・接続を再確認するまで購入許可は出しません。
- **個別部品のBF目標額は希望価格であり、実売予測や確定価格ではありません。** 価格.comなどの比較価格は市場参考値で、店舗決済価格・在庫を保証しません。部品価格を取得できない場合は0円扱いせず「未確認」とします。
- BTOのG-TUNE等は比較材料として監視を継続しますが、本体選定の主ランキングは自作構成にします。注文前に販売店の最終カート価格・送料、CPU／マザーボードBIOS、メモリQVL、GPU寸法・電源、ケース干渉、Windowsライセンスを再確認します。

## 自作とBTOの両方を比較する運用

- **自作PCも購入方法の正式な候補として監視します。** パーツ別価格・組み合わせ・互換性・送料・小物・Windowsライセンスまで計算し、組み立てに必要な確認手順は [自作PC組み立てガイド](docs/self-build-assembly-guide.md) にまとめています。
- BTO完成品も引き続き監視します。自作とBTOを同じ製品として混ぜて採点せず、レポート上で別々に表示して比較します。
- BTOは **RAM 32GB以上・SSD 1TB以上の完成構成** の最終見積で比較します。16GB/500GB等の基本価格だけで「安い」と判定せず、構成変更費をゼロと仮定しません。
- 自作はGPUの正確な型番・寸法・電源端子、CPU対応BIOS、メモリQVL等の互換性を確認します。自動チェックがPASSでも注文直前のメーカー資料確認を省きません。
- 最終選択はPC単体価格でなく、**PC＋モニター2台＋スピーカー＋キーボード＋マウス＋必要ケーブル＋送料** の総額で行います。総額・在庫・販売元・公式セール期間・構成・互換性のいずれかが未確認なら、監視は続けても購入許可を出しません。

## 自作PCパーツ監視・互換性チェック

- 個別パーツ設定：config/build_components.json。
- scripts/build_component_monitor.py は価格.comの型番一致価格を「市場参考値」として別データに保存します。BTO・ノートPCのウォッチリストには混ぜません。
- scripts/self_build_planner.py は3種類のGPU案について、部品合計・送料・小物予備費・周辺機器込み総額・基本互換性を検証し、自作構成を最新ランキングの先頭に掲載します。
- data/reports/self-build-ranking.md は部品別BF目標、比較サイト参考価格、型番ページ、互換性チェックを一覧化します。取得できない価格を0円にしません。
- 比較サイト価格をBF実売として扱わず、公式日程・店舗の確定決済価格が確認できるまでは購入許可を出しません。

## 周辺機器カテゴリ別ランキング

メインモニター、サブモニター、スピーカー、キーボード、マウス、マウスパッド、電源タップ、ケーブルをカテゴリ別に順位付けした購入ガイドは [docs/peripheral-rankings.md](docs/peripheral-rankings.md) に分離しています。各順位は「カテゴリから1商品を選ぶ」ための比較であり、全候補を同時購入するリストではありません。周辺機器の合計BF目標は¥69,800、PC本体の計画上限は¥330,200です。

## 予算の単一の正本

config/targets.json が唯一の予算設定です。budget_jpy は互換性を保つためのPC本体目標価格であり、総予算ではありません。

PC本体の上限は、周辺機器の実売価格がモデル一致済み・在庫確認済みで得られた場合に動的に再計算します。価格や在庫が未確認なら目標価格で計画額を仮計算しますが、全体購入許可は保留します。

RAM 32GB または SSD 1TBに満たない基本構成は NEEDS_CONFIGURATION とし、購入時の構成変更を含む価格が確認されるまで購入候補としての購入許可を出しません。

## 周辺機器の別系統監視

PC候補のランキングにモニター・スピーカー・マウス等を混ぜず、scripts/peripheral_monitor.py で別々に取得・記録します。価格観測は data/peripheral_prices.json、価格/在庫イベントは data/peripheral_change_events.jsonl に保存します。実売価格は商品ページのモデル一致・妥当な価格範囲・許可ホストを検証した場合のみ有効です。取得失敗は売り切れとは扱いません。

## ランキング

100点は購入優先度であって、値下げ確率や勝率ではありません。

- 性能：40点
- 価格価値：20点
- 過去セール根拠：15点
- 在庫・売り切れリスク：15点
- 購入タイミング：10点

構成不一致、参照価格、異常価格、古い観測、在庫不明、PIT不明などは安全側に処理します。購入リンクは実在する商品URLのみを出力します。大穴・アウトレットは監視しますが、根拠の弱い値段を現行価格とみなしません。

## ゲーム適性と完成PCの選定基準

FPS・Cities: Skylines IIの快適度、RTX 5070とRTX 5060 Ti 16GBの選び分け、AI・大規模予測プログラム向けの構成、動的予算上限をまとめた [ゲーム適性・完成PCガイド](docs/game-compatibility-and-build-targets.md) を追加しています。ここでの性能評価は実測FPSの保証ではなく、公式要件と構成クラスに基づく目安です。

## セール日程とGitHub Actions

- **2026年の公式セール開始日は、各ショップごとに独立して確認します。** 2025年ページの日付や曜日が一致することを根拠に、2026年の日程を推定しません。
- 広域監視窓：**2026-11-01 00:00 JST ～ 2026-12-11 23:59 JST（暫定設定）**。これは価格観測・履歴収集用の範囲であり、どのショップの公式BF開始日・終了日を意味しません。
- `scripts/official_campaign_dates.py` はショップ公式URLと、同一公式ドメイン上で見つかったキャンペーン関連リンクを各店舗3ページまで確認し、2026年と明記された日付範囲のみを検出します。年なしの日付・前年の日付・別ドメインへの遷移は開催日確認に使いません。店舗URL設定が変わった場合は6時間キャッシュを無効化します。結果は `data/official_campaign_dates_status.json` に保存します。
- `scripts/sale_calendar.py` は購入先URLと公式日付確認結果を結び付けます。公式日程が未確認、売り手が特定できない、または価格観測が公式期間外の場合は、観測価格を「BF実売」と判定せず、買い時の購入許可を出しません。買い時レポートでは日程を確認できない店舗数とアクセス失敗店舗数を分けて表示します。
- 通常時：実データ取得は約15分ごと。暫定広域監視窓：実データ取得は約5分ごと。監視窓の値は `config/targets.json` が唯一の設定元です。手動の高速監視と watchdog も同じ設定を参照し、11月14日などの固定日付を公式開催日として扱いません。高速監視も公式日程チェッカーを先に更新してから判定レポートを生成します。
- メイン監視ワークフローだけが定時起動を担当し、同時書き込みは直列化します。Python標準ライブラリとGitHub Actions中心で無料運用し、有料APIを必須にしません。

処理順序：monitor → peripheral_monitor → recover → sanitize → official_campaign_dates → report → timing → scenario → healthcheck → validate → commit/push。

## 主な出力

- data/current_latest.json：PCの現行価格・在庫・処理率。
- data/peripheral_prices.json：周辺機器のモデル一致済み価格と在庫。
- data/change_events.jsonl：PC価格・在庫の変化履歴。
- data/peripheral_change_events.jsonl：周辺機器の価格・在庫の変化履歴。
- data/decision_rankings.json：100点ランキング、予算・購入ゲート、元観測スナップショットSHA256。
- data/scenario_analysis.json：PC目標価格に対する割引シナリオ（値下げ確率の予測ではない）。
- data/timing_analysis.json：価格変更時刻の分析。
- data/official_campaign_dates_status.json：各ショップの公式2026年開催日程の確認状態、参照URL、日付範囲、取得結果。未確認日はnullのままにします。
- data/buy_now_observations.jsonl：暫定広域監視窓に取得した価格の時系列スナップショット。SKU一致・直接構造化価格・PIT・在庫が確認された観測のみを保存し、窓内最低観測価格を追跡します。窓内最低価格は公式BF価格や販売店の全履歴最安値とは限りません。
- data/buy_now_decision.json：セール全期間の「今買う／値下げ待ち／公式日程確認待ち／データ確認待ち」判定、暫定監視窓内の観測最低価格と時刻、在庫・PIT・完成構成・予算ゲート、購入リンク。購入許可には販売元ごとの公式2026年期間確認が必要です。
- data/reports/buy-now-now.md：スマホで確認しやすい最新の買い時レポート。公式日程未確認のときは、広域監視窓と実際の公式セール期間を明確に分離します。
- data/reports/latest.md：総予算、周辺機器の価格確認、候補ランキング、購入リンクに加えて「今この瞬間の買い時判定」を表示。

## 取得失敗の診断と検索フォールバック

直接商品ページの取得に失敗した場合、無料の検索HTMLソースを順に試します。ただし検索結果のタイトル/抜粋にカタログ登録済みSKU・型番別名が含まれる場合のみ価格候補に採用し、販売ページのSKU一致、価格妥当性、在庫、PITの検証は省略しません。ホスト別・原因別の取得エラー、検索試行、採用、SKU不一致除外件数をレポートに出力します。取得失敗は売り切れとは扱いません。

## Fail-closed方針

取得失敗は売り切れではありません。表示価格・参照価格・値引き額・クーポン・ポイントを混同しません。価格・在庫・PCの完成構成・予算内総額のいずれかが不明な場合、ランキング上の監視は続けても全体購入許可は出しません。

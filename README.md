# Black Friday PC Price Intelligence

2026年ブラックフライデーに向けて、自作PCの部品価格・在庫・互換性と周辺機器の購入条件を無料で監視・検証するプロジェクトです。GitHub Actionsは証拠データの継続収集、ChatGPTは依頼時点の最新情報を用いた最終分析を担当します。

## ランキングの点数

自作構成レポートに**100点構成スコア**と用途別内訳を表示します。採点軸はゲーム、ゲーム制作、分析・AI、勉強/同時利用、BF目標総額ベースの価格効率、互換性です。ゲーム点はTom's Hardwareの2026年GPU階層にある1440p Ultraラスタライズ値を正規化した代理指標で、対象ゲームの実測FPS・予測ではありません。

別枠の**購入根拠充足度（100点）**は、直接価格・型番一致・取得時刻・販売可能在庫・検証済み決済総額・互換性の確認状況を測ります。価格比較サイトの参考値だけで、直接在庫や決済総額の確認済みとはみなしません。この値も購入許可ではありません。詳細：[スコア算定ルール](docs/scoring-method.md)。

## 運用原則

**最終的なおすすめ順位**は、GitHubの中間的な診断情報ではなく、ユーザーが依頼した時点でChatGPTが最新証拠を検証して作成します。

- GitHub Actionsは価格、在庫、型番、公式セール日程、価格履歴、取得失敗、データ品質を継続収集します。
- 自動生成のランキングや買い時判定は内部診断用の中間的な診断情報です。最終順位はユーザーから依頼があった時点で、ChatGPTが最新データと必要な外部情報を再検証して作成します。
- 「BF購入目標」「セール前の参考価格」「現在の観測価格」「公式キャンペーン期間内の確認価格」「最終決済額」を明確に分けます。目標価格は値下がり予測や実売価格ではありません。
- 取得失敗は在庫切れを意味せず、型番や販売元が曖昧な価格を確定値にしません。未確認項目は未確認のまま記録します。
- ブラックフライデーで値下がりする可能性だけで買い時を決めず、価格・在庫・互換性・返品条件と総額で判断します。

## 購入時期のルール

ブラックフライデーを基本に待つ一方、設定した低価格トリガーを満たす前倒し候補は、型番・新しい直接価格・在庫・送料込み決済額・保証/返品・互換性・40万円総額を検証して再判定します。価格トリガーは予測や購入許可ではありません。詳細：[前倒し購入とBF待ちの判定ルール](docs/purchase-timing-policy.md)。

## 用途要件：ゲーム制作も主要目的

遊びたいゲームを快適に動かすだけでなく、**自分でゲームを作ること**もPC選定の必須要件です。エンジンは決め打ちせず、Unreal Engine 5 / Unity / Godotによる2D・3Dゲーム、FPS試作、都市建設・シミュレーション制作を想定します。エンジンの編集画面、IDE、デバッガー、コンパイル/ビルド、ブラウザー、テスト、Python/AI・データ分析を並行させる状況も評価します。

- 購入時の基準はRAM 32GB以上・専用GPU VRAM 8GB以上・SSD 1TB以上。UE5の公式推奨仕様はRAM 32GB、グラフィックスメモリ8GB以上です。
- 64GB RAMと2TB SSDは、予算と最終価格が許せば優先しますが、必須の公式要件とは扱いません。購入時点で搭載された容量のみ適合判定に使い、購入後の増設を前提にしません。
- RTX 5070 12GBはゲーム性能と制作の総合候補、RTX 5060 Ti 16GBはVRAM重視の候補、RTX 5070 Ti 16GBは性能重視の大穴です。GPUの優劣はFPSだけで決めず、VRAM、描画性能、総額、電源、寸法を別々に評価します。
- 現在のRyzen 7 9700X（8コア/16スレッド）は通常のゲームプロジェクト制作の土台です。ただしUnreal Engine自体をソースからローカルでフルビルドする場合、Epicの12～16コアという実用目安よりコア数が少ないため、その特殊用途は明示的なトレードオフとして報告します。

参照：[Epic Games — Unreal Engine 5.8 ハードウェア/ソフトウェア要件](https://dev.epicgames.com/documentation/en-us/unreal-engine/hardware-and-software-specifications-for-unreal-engine)、[Unity 6 システム要件](https://docs.unity3d.com/6000.0/Documentation/Manual/system-requirements.html)。

## 勉強・分析・普段の作業も同時に行う前提

ゲーム/ゲーム制作だけで用途を狭めません。学校の勉強、PDF・資料の読解、Web調査、動画教材とノート、レポート・発表資料の作成、ブラウザーの複数タブを快適に使えることも評価対象です。さらにPython、GitHub、データ処理、スポーツ・株式・BTC予測、自動テスト、実行可能な範囲のローカルAIを同じPCで動かす想定です。

そのためGPUだけでなく、CPUのシングル/マルチコア性能、RAM、VRAM、SSD容量と持続性能、長時間稼働時の冷却・騒音、複数ツール同時利用の応答性で比較します。基本は購入時32GB RAM・1TB SSD以上。予算が許せば64GB RAM・2TB SSDも、**完成構成の実価格が確認できる場合に限り**優先候補にします。後からの増設を前提にしません。勉強やデータ分析のすべてがGPUで速くなるわけではないため、用途ごとのボトルネックを分けて評価します。

## 予算と購入条件（2026-10-17更新）

- **総予算の絶対上限：400,000円**（PC本体＋周辺機器＋PC側送料/必要小物＋総額予備費込み）。
- **PC本体の基準目標：360,000円**。購入可能上限は総額400,000円から実際の周辺機器費と総額予備費5,000円を差し引いて動的に計算します。周辺機器が安く済んでも差額を必ず使う必要はありません。
- **周辺機器の計画配分は約35,000円**です。使い切る義務でもハード上限でもありません。ネット送料込み総額・店頭価格・必要性に応じてPC本体との配分を調整します。
- PC本体は自作方式を本命とし、組み立て時間は制約・減点にしません。BTO完成品は同等構成の価格比較用ベンチマークです。
- PCは購入時点で**RAM 32GB以上、SSD 1TB以上**。購入後の増設を前提に合格扱いしません。64GB RAM / 2TB SSD は、購入時点で総額内に収まり、価格と互換性が確認できる場合だけ追加評価します。
- モニターは**27インチWQHDのメインモニター1台のみ**です。サブモニターは購入対象・候補・価格監視・予算・総額計算に含めません。ヘッドセットも購入対象外です。
- **スピーカーは購入対象外です。** 商品候補・価格監視・ランキング・予算計算から完全に除外します。
- 周辺機器は商品ごとにネット配送・実店舗の現金購入・ネット注文の店舗受け取りを比較します。福岡の実店舗候補はビックカメラ天神1号館・ヨドバシカメラ マルチメディア博多です。ネット配送は送料を含む最終支払額を確認し、実店舗購入では店頭の税込現金価格と店舗在庫を確認します。ポイントは現金値引きと分け、ネット価格を店頭価格の証拠にしません。
- 価格目標・セール前参考価格・確認済みBF価格・最終決済価格を区別します。型番、在庫、互換性、送料、返品条件が未確認なら購入許可は出しません。
- **購入後の継続費用は原則0円**。無料・オープンソース・ローカル実行を優先し、有料AI月額、従量課金API、クラウドGPU、有料データセットを中核依存にしません。詳細：[継続課金なしの運用方針](docs/zero-recurring-cost-policy.md)。

以下は部品のブラックフライデー購入目標を合算した計画値で、確認済みの完成構成価格や価格予測ではありません。計画総額はPC本体＋周辺機器35,000円＋総額予備費5,000円です。

| 順位・役割 | CPU / GPU | PC本体目標 | 周辺機器35,000円＋予備費込みの計画総額 |
|---|---|---:|---:|

| VRAM重視 | Ryzen 7 9700X + RTX 5060 Ti 16GB | 280,600円 | **320,600円** |
| 性能重視の大穴 | Ryzen 7 9700X + RTX 5070 Ti 16GB | 324,800円 | **364,800円** |

これらはすべてBF購入目標価格による合算で、現行実売価格ではありません。RTX 5070 12GBをバランス候補、RTX 5060 Ti 16GBをVRAM重視の代替、RTX 5070 Ti 16GBを性能重視の大穴として残します。目標価格を達成したことにして購入許可は出しません。

### 分析・ゲーム制作寄りの代替案：RAM 64GB＋RTX 5060 Ti 16GB

都市シミュレーションの規模、Unity/Unrealのアセット、複数の開発ツール、大きな分析データをより重視する場合は、GPUをRTX 5060 Ti 16GBに抑えてRAM 64GBを購入時に確保する別案も監視します。

- 64GBキット候補：Lexar THOR RGB 2nd Gen DDR5-6000 64GB（32GB×2）、型番 LD5U32G60C40BV-RGD。[アークの商品ページ](https://www.ark-pc.co.jp/i/11650134/)
- 2026年10月17日に確認できる商品ページ表示は119,990円（期間限定セール、通常表示154,800円、期限10月29日23:59）。セール条件はブラックフライデーまで続く保証はありません。[商品・価格](https://www.ark-pc.co.jp/i/11650134/)
- RAM 64GBのBF目標を100,000円、既定の32GB目標を40,000円とすると、差額60,000円。RTX 5060 Ti 16GB構成はPC本体目標340,600円、周辺機器35,000円、予備費5,000円込みで**380,600円**となります。
- この案はメモリ容量・VRAM容量を優先する別構成です。RTX 5070 Tiと64GB RAMを同時に選ぶとこの価格目標では40万円を超えるため、同じ推奨構成に混ぜません。
- 正確な型番のQVL、BIOS、EXPO安定性、店頭在庫、最終決済価格が未確認なら採用しません。100,000円はBF購入目標であって価格予測ではありません。

### 40万円を活かす条件付き案：2TB SSDへの置き換え

ゲーム本体、Unity/Unrealのアセット、ビルド成果物、分析データを同居させるため、SSD 2TBへの置き換え候補を追加しました。後から増設する前提ではありません。

- 監視SKU：KIOXIA EXCERIA BASIC SSD-CK2.0N4B/N 2TB。[メーカー仕様](https://www.kioxia.com/ja-jp/personal/ssd/exceria-basic.html)
- 2026年10月の価格比較結果には、監視SKU /N について52,980円からの掲載と、別のページ取得で68,280円（店舗1件）の表示例があります。[検索結果の表示](https://search.kakaku.com/SSD%20SSD-CK2.0N4B%2FN/) [個別の価格比較ページ](https://kakaku.com/item/K0001719361/) ページ・店舗・在庫条件が異なるため、どちらも購入直前の決済価格とは扱いません。45,000円は積極的なBF目標で、実売予測ではありません。
- 1TBのBF目標18,000円から差額27,000円で置き換えられた場合、RTX 5070 Ti構成はPC本体351,800円、周辺機器35,000円、予備費5,000円込みで**391,800円**です。
- これはすべての目標価格を達成した場合のシナリオです。価格や在庫が目標に届かなければ1TB構成やGPU代替を再比較し、総額上限400,000円を超えません。QLC NANDのため継続的な大容量書き込みにはTLC候補との比較も行います。

## 値上がりリスクの監視方針

- **優先1：GPU。** 国内RTX 50シリーズ価格の国際比較差とモデル別の在庫・実売の変化を監視。ただし海外価格との差は将来値上がりの確定証拠ではありません。
- **優先2：CPU。** 秋葉原の2026年10月前半価格調査でRyzen 7 9700Xは51,800円（前回調査比+29.6%）、9800X3Dは74,800円（+24.7%）と報告されました。これは調査時点の国内価格変化であり、全販売店の価格を示すものではありません。
- **優先3：DDR5メモリ。** TrendForceは2026年第4四半期の従来型DRAM契約価格を前期比+10〜15%と予測しています。個別メモリキットの店頭価格が同率で上がるという意味ではありません。
- **優先4：SSD/NAND。** TrendForceは同四半期のNAND契約価格を+15〜20%と予測していますが、個別消費者向けSSDの実売は製品や販売店で異なります。
- マザーボード、電源、ケース、冷却、周辺機器は、一般論だけで一律の値上がりを断定せず、型番別の価格・在庫変化で判断します。

詳細なルールと出典：[値上がりリスク判定プレイブック](docs/price-rise-risk-playbook.md)

## セール日程・監視間隔

- 各店の2026年ブラックフライデー公式開催日程は、年付きの日付範囲を公式ページで確認するまで未確定です。
- 暫定の広域監視窓は `2026-11-01 00:00 JST`〜`2026-12-11 23:59 JST` です。これは価格を集めるための監視窓であり、**公式開催日程ではありません**。11月14日などの特定日をすべての店の開始日とは扱いません。
- 通常期間は約15分ごと、暫定の広域監視窓では約5分ごとに観測する設定です。正確な実行状況は [GitHub Actions](https://github.com/sasasotaro1202-star/Black-Friday-PC-Price-Intelligence/actions) を確認します。
- 監視期間内の価格でも、販売元の2026年公式キャンペーン期間、正確な商品型番、在庫、適用条件、取得時刻（PIT）が揃っていなければ「BF期間内の確認済み価格」として採用しません。

## 在庫切れ・在庫不明・掲載価格の扱い

**同じ型番でも販売店ごとの在庫を独立して記録します。** 最安の表示価格だからといって、売り切れ価格を買える価格として選びません。

- `in_stock`（在庫あり）／`low_stock`（在庫少）だけを、鮮度が確認できた場合に販売可能な掲載価格として集計します。購入判断時はさらに最終カート・決済額・配送先への在庫を再確認します。
- `out_of_stock`（在庫切れ）はその販売店の購入価格に使いません。別店舗に同じ正確な型番の在庫があれば候補に残します。
- `unknown`（在庫不明）、`preorder_or_backorder`（取り寄せ・予約）、アクセス拒否、タイムアウト、価格解析失敗は売り切れと同一視しません。購入可否が確認できない状態として保留します。
- 同じ部品の販売店情報は個別の価格・在庫・URL・取得時刻付きで表示します。通常時の在庫シグナルは60分、暫定の高頻度監視窓内は30分より古い情報を「現在在庫あり」の根拠に使いません。古い観測は参考履歴として残し、販売可能価格としては集計しません。
- 「販売可能掲載価格の部分小計」は、鮮度のある在庫あり／在庫少の直接販売店掲載額だけを足したものです。必要部品すべての価格・在庫が揃わない場合は部品数カバー率と未確認パーツを併記し、総額を完成PC価格や最終決済価格として表示しません。価格の欠落をBF購入目標で埋めません。

# Black Friday PC Price Intelligence

2026年ブラックフライデー向けゲーミングノートPCの価格・在庫・購入条件を無料で時系列監視する基盤です。

## 目的
- 公開Webの価格・在庫を高頻度で観測
- 変更を検出した時点を日本時間で保存
- 過去の公開価格データと2026年の自前観測を分離
- 「今買う / 待つ」を価格だけでなく在庫リスクまで含めて判断
- 28万円前後に到達する可能性が低い高性能機も候補として残す
- 価格変化の時期・セール開始前後・在庫リスクを分析する
- 最終的に最大3台だけを購入候補として表示

## 予算・ターゲット
- 目標支払額: 約280,000円（税込）
- ブラックフライデー想定日: 2026-11-27
- 監視対象は約28万円以下だけに限定せず、価格が高くても28万円到達に必要な値下げ率と性能で評価する
- 特に RTX 5070 Ti / RTX 5080 Laptop、高TGP、上位HX/HS CPU、32GB以上、1TB以上を優先

## 観測時刻
observed_at は「このシステムがその価格・在庫状態を確認した時刻」です。
販売店内部の正確な変更時刻を推測して断定しません。
記事公開時刻やセール開始時刻も、内部の値札変更時刻とは区別します。

## 対象
Lenovo / ASUS / HP / MSI / Acer / GIGABYTE / マウスコンピューター / ドスパラ等の日本向け販売ページを優先。
Amazon.co.jp、楽天市場の公式/正規販売店、ヨドバシ、ビックカメラ、ヤマダ等も候補。

## 自動監視
- 通常監視: 15分間隔。毎時0分を避けた分指定でスケジュール遅延リスクを抑える
- ブラックフライデー想定期間: 11/14〜12/4は上位30候補を5分間隔で追加監視（2026年の正式日程が公開されたら自動判断ロジックの前提を更新）
- ウォッチリスト: 毎日更新。空の場合は通常監視が自動でブートストラップ
- 価格変更イベント: data/change_events.jsonl に追記
- 100点購入ランキング: data/decision_rankings.json と data/reports/latest.md に保存
- タイミング分析: data/timing_analysis.json と data/reports/timing_analysis.md に保存

## 時間分析
過去の公開セール日程・価格確認時刻と自前観測を使って、
- 先行セール
- サプライズ/プレビュー
- 本セール直前
- ブラックフライデー当日
- Cyber Monday / セール後半
- セール終了直前
を比較します。

ただし、公開情報だけでは販売店内部の正確な価格変更時刻を確定できないため、
「何時に必ず下がる」とは断定せず、監視すべき時間帯の優先度として扱います。

## 失敗時の扱い
取得エラーを売り切れとは解釈しません。
価格・在庫が取れない場合は unknown / error のまま保存し、購入判断から除外します。

## 無料運用
GitHub Actions の公開リポジトリ上で実行し、外部の有料APIを必須にしません。

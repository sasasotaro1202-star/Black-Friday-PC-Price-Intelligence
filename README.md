# Black Friday PC Price Intelligence

2026年ブラックフライデー向けゲーミングノートPCの価格・在庫・購入条件を無料で時系列監視する基盤です。

## 目的
- 公開Webの価格・在庫を高頻度で観測
- 変更を検出した時点を日本時間で保存
- 過去の公開価格データと2026年の自前観測を分離
- 「今買う / 待つ」を価格だけでなく在庫リスクまで含めて判断
- 最終的に最大3台だけを購入候補として表示

## 観測時刻
observed_at は「このシステムがその価格・在庫状態を確認した時刻」です。
販売店内部の正確な変更時刻を推測して断定しません。

## 対象
Lenovo / ASUS / HP / MSI / Acer の日本公式を優先。
Amazon.co.jp、楽天市場の公式/正規販売店、ヨドバシ、ビックカメラ、ヤマダ等も候補。

## 優先スペック
1. RTX 5080 Laptop 16GB級 + 上位CPU + 32GB以上
2. 高TGP RTX 5070 Ti Laptop 12GB級 + 上位CPU + 32GB以上
3. RTX 5090 Laptop 24GB級が40万円前後で購入可能なら特別候補

予算: 購入時支払額40万円程度まで。

## 失敗時の扱い
取得エラーを売り切れとは解釈しません。
価格・在庫が取れない場合は unknown / error のまま保存し、購入判断から除外します。

## 無料運用
GitHub Actions の公開リポジトリ上で実行し、外部の有料APIを必須にしません。

# 自作PCスコア算定ルール

更新日: 2026-10-17

## 100点満点の構成スコア

対象は同じ基準の自作PC構成です。スコアは予算配分を含めて構成同士を比較する補助指標で、実測性能や購入許可の代わりではありません。

|評価軸|配点|算定|
|---|---:|---|
|ゲーム|25|Tom's Hardware GPU Benchmarks Hierarchy（2026年6月24日更新）の1440p Ultraラスタライズ基準FPSをRTX 5070 Tiの値で正規化。測定値は同ベンチマークの広いゲームセットの参考値で、Cities: Skylines II / Apex / VALORANT個別のFPSではない。|
|ゲーム制作|20|VRAM最大8点、RAM最大5点、SSD最大3点、CPUコア数最大4点。|
|分析・AI|20|CPUコア数最大7点、RAM最大6点、VRAM最大5点、SSD最大2点。すべての分析がGPUで速くなるとは仮定しない。|
|勉強・同時利用|10|RAM最大5点、CPUコア数最大3点、SSD最大2点。|
|目標価格ベースの価格効率|15|上記4用途の得点合計 ÷ BF目標総額（PC・周辺機器・予備費込み）を比較対象内で正規化。現行決済価格ではない。|
|互換性|10|互換性チェックをPASS=1、REVIEW=0.5、FAIL=0として平均し、10点換算。未確認をPASS扱いしない。|
|**合計**|**100**|用途別4項目＋価格効率＋互換性の合計。|

### ゲーム点の参照値

出典: [Tom's Hardware — GPU Benchmarks Hierarchy 2026](https://www.tomshardware.com/reviews/gpu-hierarchy,4388.html)、最終更新 2026年6月24日。ラスタライズ性能の1440p Ultra列の括弧内の参照FPSを使います。

|GPU|参照FPS|ゲーム点の計算|ゲーム点/25|
|---|---:|---|---:|
|RTX 5070 Ti 16GB|116.8|25 × 116.8 / 116.8|25.0|
|RTX 5070 12GB|96.4|25 × 96.4 / 116.8|20.6|
|RTX 5060 Ti 16GB|73.4|25 × 73.4 / 116.8|15.7|

これは同じ試験条件で比較できる一般的なラスタライズ性能の代理指標です。対象ゲーム、画質設定、CPUボトルネック、DLSS/Frame Generation、ドライバー、GPUの個別カード冷却差で実際の結果は変わります。個別ゲームのFPS保証には使いません。ソースが更新された場合は値・確認日・テスト条件を再確認し、点数も再計算します。

価格効率は比較対象が増減すると正規化基準も変わります。異なる候補集合で算出された点数は、そのまま横比較しないでください。構成変更、目標価格変更、実売総額の確認後には再採点が必要です。

## 購入根拠充足度（構成スコアと別枠）

これは「買ってよい」という判断ではなく、購入前の根拠がどこまで実際に確認できているかを示します。

|根拠|配点|条件|
|---|---:|---|
|直接価格・型番一致・取得時刻（PIT）|30|正の価格があり、直接価格・正確な型番一致・価格の有効時刻と取得時刻が検証済み。|
|販売可能在庫|25|上記の正確で新しい直接価格があり、在庫が in_stock または low_stock。|
|検証済み決済総額|25|販売可能在庫が確認でき、正の送料・必須費用込み決済総額を直接検証済み。送料込み概算は不可。|
|互換性の確認状況|20|互換性点（10点満点）を20点満点に換算。FAILやREVIEWは満点にならない。|

必要部品のうち、正確な価格・在庫・決済総額を確認できた部品の割合で各配点を計算します。価格比較サイトの参考価格だけでは、直接価格・在庫・決済総額の確認済み点に加算されません。

根拠充足度が高くても、保証、返品、最終カート、公式セール適用条件、全体40万円上限、BIOS/QVL/寸法/電源配線などの最終チェックは別途必要です。購入許可や自動注文は出しません。

## 周辺機器：適合点と購入根拠点は別管理

周辺機器ランキングには、次の2種類の点数を並べます。

### 用途適合点/100

`config/targets.json` の `ranking_score_100` を表示します。これはユーザーの用途、製品仕様、予算目標を調べて登録した事前の適合評価です。市場価格や在庫が変化しても自動で変わる点数ではなく、独立した実機ベンチマークでもありません。候補の基本的な使いやすさ・仕様適合を比較するために使い、現在買えるかどうかの判断には使いません。

### 購入根拠点/100（動的）

レポート生成時に、最新の販売店観測から次の配点で再計算します。

|根拠|配点|加点条件|
|---|---:|---|
|直接価格・型番一致・取得時刻/PIT|30|価格が正数、正確な型番一致が確認済み、価格の有効時刻が取得時刻以下、取得データが鮮度上限内|
|販売可能在庫|25|現在の型番一致観測で在庫あり。残りわずかは18点。売り切れ・予約・不明・鮮度切れは0点|
|検証済み決済総額|25|送料等を含む決済額、価格、在庫が同一購入ルートで確認済み。送料予備額や推計総額では加点しない|
|購入ルート比較|10|対象商品で必要な購入ルートの比較が完了している。未比較・店頭価格未確認は加点しない|
|保証・返品条件|10|保証と返品条件の確認が明示的に記録されている|

通常監視中は価格情報の鮮度上限を6時間、在庫情報の鮮度上限を30分とします。実際の購入時には販売店のカート・配送条件・在庫を再確認します。情報が未取得・古い・曖昧な場合は推測で加点しません。在庫切れはその販売店の購入候補から外しますが、同一製品の別販売店や代替品を確認する理由として残します。

この購入根拠点はデータの確認度であり、商品の品質・性能点とは違います。高得点でも購入許可にはなりません。カテゴリ内の順位は用途適合点を基本にし、売り切れ・在庫不明・価格未達の候補は購入アクションでは別判定します。

### 点数を読む上での重要事項

- 自作PCの構成点は、PC一式としてのゲーム・制作・分析/AI・学習/同時利用・目標価格効率・互換性の評価です。個別パーツ単体の性能点ではありません。
- BTO完成品の点数は、確認できたスペック・価格・候補識別情報に基づく候補比較です。基本構成と増設後構成を同一価格として扱いません。
- 周辺機器の用途適合点は事前登録の評価、購入根拠点は現時点の販売証拠です。同じ「100点満点」でも測る対象は異なります。

## 解釈の限界

1. GPUゲーム点は出典値を透明に正規化した proxy であり、個別ゲームの実測FPSや性能予測そのものではありません。
2. 点数は個別ゲームFPS、シェーダーコンパイル、Unreal/Unityビルド時間、ローカルAIのトークン速度を予測する数値ではありません。
3. BF目標価格は購入希望値で、実売価格・値下がり予測・BFでの達成保証ではありません。
4. RAM 32GB・SSD 1TB以上は購入時の構成を評価し、購入後の増設を前提に加点しません。
5. 購入根拠充足度はデータの整備状況です。構成性能が低いことを意味せず、また購入安全性の保証でもありません。

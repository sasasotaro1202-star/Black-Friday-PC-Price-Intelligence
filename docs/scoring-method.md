# 自作PCスコア算定ルール

更新日: 2026-10-17

## 何を点数化するか

レポートの「構成スコア」は、同一のブラックフライデー（BF）目標構成を比較するためのルーブリックです。構成の方向性を比べる指標で、購入許可や販売価格の検証結果を代替しません。

|評価軸|配点|採点方法|
|---|---:|---|
|ゲーム|25|GPUの相対的な製品階層を使う判断スコア。RTX 5070 Ti 9.6/10、RTX 5070 8.8/10、RTX 5060 Ti 8.1/10を25点に換算。独立ベンチマークや実測FPSではない。|
|ゲーム制作|20|VRAM（8点）、購入時RAM容量（5点）、購入時SSD容量（3点）、CPUコア数（4点）。|
|分析・AI|20|CPUコア数（7点）、RAM（6点）、VRAM（5点）、SSD容量（2点）。すべての分析がGPUで速くなるとは扱わない。|
|勉強・同時利用|10|RAM容量（最大5点）、CPUコア数（最大3点）、SSD容量（最大2点）。|
|価格効率|15|上記4用途の得点合計を、構成のBF目標総額（周辺機器・予備費込み）で割り、比較対象の中で最高の比率を15点に正規化。現行決済価格ではなく目標価格を使うため、現在の実売価値とは別。|
|互換性|10|互換性チェックをPASS=1、REVIEW=0.5、FAIL=0として平均し、10点に換算。未確認をPASSとして扱わない。|
|**総合**|**100**|各軸の合計を100点満点で表示。比較対象やBF目標価格が変更されると、価格効率と順位も変わり得る。|

### 購入準備度（構成スコアとは別）

- **価格根拠のカバー率 65%**：その構成に必要な部品のうち、型番・鮮度・時刻・ソース要件を満たす信頼できる市場参考価格を確認できた割合。
- **互換性確認 35%**：上記の互換性スコアを100点換算して反映。
- 価格根拠や在庫が不足すれば準備度は下がります。準備度が高くても、最終決済価格・在庫・返品条件・全体予算・互換性を直前に確認する必要があり、**自動購入許可は絶対に出しません**。

## 読み方と限界

1. 総合点は構成を比較するための補助指標で、唯一の購入判断基準ではありません。
2. GPUのゲーム点は明示された相対的な階層判断です。実測FPS、ゲーム別設定、電力/温度の測定値、エンジンのビルド時間を意味しません。
3. 価格効率は確認済み実売価格ではなく、設定中のBF目標総額に基づきます。「目標価格達成」を仮定した試算なので、BF時点では実際の現金決済総額で再計算が必要です。
4. 購入準備度は証拠収集の進捗を数値化したものです。低いスコアは性能が低いという意味ではなく、購入根拠が不足していることを示します。
5. 選択肢を追加・削除すると価格効率の正規化基準が変わるため、異なる版の総合点をそのまま比較しないでください。
6. RAM 32GB・SSD 1TBの基準を満たす購入時構成を評価します。購入後の増設を前提に加点しません。

# 周辺機器のネット価格・店頭価格・店舗受け取りの比較ルール

更新日：2026-11-03（JST）。

## 基本方針

周辺機器は、ビックカメラ天神1号館とヨドバシカメラ マルチメディア博多の**両支店**について、同一型番の税込現金価格と同じ支店の在庫状態を確認してから購入ルートを選びます。価格・在庫は支店ごとに独立した証拠で確認し、別支店の価格と在庫を組み合わせません。

両支店のどちらか一方でも未確認なら、ネット配送・ネット注文の店舗受け取りへ自動切替しません。選択ルートは `unconfirmed` のままにし、ネット掲載価格は比較参考としてのみ表示します。両支店の比較が完了した後に限り、オンラインの正確な型番・販売元・販売可能在庫・実送料/必須費用・最終決済額・保証/返品条件も確認して購入候補に加えます。未確認の価格・在庫・送料・決済額は推測で補いません。

## 比較する購入ルート

- **ネット配送：** 正確な型番・色・販売元/出品者、新品状態、税込商品価格、配送可能な在庫、送料・必須手数料、最終決済額、納期、保証、返品条件を確認します。送料・必須費用が未確認なら予備額を用いた推計として表示し、最終現金支払額とは呼びません。
- **実店舗の現金購入：** ビックカメラ天神1号館・ヨドバシカメラ マルチメディア博多について、正確な型番・色、同一支店の税込現金価格、同一支店の在庫、確認時刻、証拠URLを別々に確認します。全国向けWeb価格やネット取置き在庫を店頭現金価格・棚在庫の証拠として流用しません。
- **ネット注文・店舗受け取り：** オンライン決済額、対象支店、受け取り在庫、受け取り可能時刻を別ルートとして確認します。店頭現金価格や通常配送の価格とは同一視しません。

## 候補選択と比較状態

- 正確な型番・販売元・直接価格・在庫・必要費用が検証できた候補だけを、購入可能ルートの比較に使います。
- 同一支店の現金価格と在庫は同じ支店の証拠で結び付けます。別支店の価格と在庫を組み合わせません。
- **両支店それぞれ**の正確な型番・税込現金価格・同じ支店の在庫状態が揃うまで、いずれの支店も最終選択せず、購入ルートを `unconfirmed` とします。
- ネット配送・店舗受け取りの価格は、両支店の比較が完了するまで参考情報のみです。両支店の比較完了後も、オンライン側の実送料・最終決済額・販売可能在庫・保証/返品条件が揃わなければ、オンライン購入ルートは選択しません。
- あるルートが未確認なら、そのルートを売り切れと扱わず、比較未完了として残します。
- すべてのルートが確認できた場合だけ「全ルート比較完了」とします。確認済み候補だけで選んだ場合は「確認済みルート内の暫定最安」と表示します。
- 自動選択は購入候補の提示であり、注文の実行・自動購入許可ではありません。購入直前に決済画面、配送先、在庫、保証、返品条件を再確認します。

## 価格・送料・ポイントの区分

- BF購入目標は希望値であり、現在の実売・値下がり予測・注文可能価格ではありません。
- ネット商品ページの `current_price_jpy` はネット掲載価格です。店頭の `store_price_jpy` として流用しません。
- `online_shipping_jpy` は決済画面等で実額が確認できた場合だけ記録し、`online_shipping_cost_verified=true` とします。未確認中は `online_shipping_reserve_jpy` を推計用の予備額として使い、実際の送料とは表示しません。
- 最終現金支払額は、正確なSKU・販売元・購入ルート・配送/受取方法・送料・必須費用・適用済みクーポンを同じ決済条件で確認した場合だけ確定扱いにします。
- クーポンは最終決済画面で適用を確認した場合だけ反映します。ポイント、延長保証、同梱品等は現金支払額と分け、ポイントを現金値引きに算入しません。
- ネット注文の店舗受け取りは、オンライン決済額と受け取り支店の在庫を別々に確認します。

## 店頭価格・在庫の記録項目（支店ごとに独立）

**支店ごとに価格・在庫を別のレコードとして記録します。** 価格・在庫が同じ支店、同じ型番、同じ確認時点の証拠で結び付いていることを必須にします。

- `store_id`: 支店ID
- `price_jpy`: その支店の税込・現金支払価格
- `checked_at`: 価格と在庫を確認したJST時刻
- `confirmation_url`: 該当支店の価格証拠となる公式HTTPSページ
- `evidence_type`: `in_store_check` / `store_phone_confirmation` / `official_branch_price_page`
- `evidence_notes`: 型番、税込現金価格、確認方法。ポイント・クーポンは別記

支店別在庫ページは在庫の証拠にはなりますが、店頭価格の証拠にはなりません。店頭価格と在庫の片方だけが確認できた場合は、もう片方を推測で補いません。

## 鮮度・エラー処理

コードは確認時刻、支店ID、証拠種類、型番照合、公式支店URLを検証します。通常監視時の実店舗証拠は最大60分、暫定BF高頻度監視時は最大30分を目安にし、設定済みの監視鮮度基準を適用します。期限超過、未来時刻、必要項目不足、支店不一致は有効な店頭価格/在庫として扱いません。

ネット商品ページの取得エラー、価格欠損、販売元不明、型番不一致、在庫不明は売り切れと同一視しません。商品ページ・監視ページのURLを保持し、取得エラー時もリンクを提示します。取得失敗を理由に別型番の価格を流用しません。

## 自動監視の限界

`scripts/peripheral_monitor.py` は設定された商品ページURLを個別に取得し、正確な型番・価格・在庫を検証します。自動取得では最終カートの配送費、個人/会員別クーポン、実店舗の棚在庫、店頭現金価格、保証・返品条件を常に取得できるとは限りません。未取得は未確認として保持し、最終決済額・保証・返品条件が未確認の候補に購入許可を出しません。

スピーカー、サブモニター、ヘッドセットは今回の購入対象外です。電源タップは所有済みのため対象外です。メインモニターは27インチWQHDを1台だけとし、ケーブルは付属品を確認して不足する場合だけ購入します。

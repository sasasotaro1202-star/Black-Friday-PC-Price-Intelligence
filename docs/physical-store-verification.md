# 周辺機器のネット価格・店頭価格・店舗受け取りの比較ルール

更新日：2026-10-17（JST）。目的は、購入先をあらかじめ固定せず、同じ型番・色・仕様について最終現金支払額と入手可能性を比較することです。

## 選べる購入ルート

- **ネット配送：** 正確な型番・販売元、商品価格、送料・必須手数料、配送/在庫、保証、返品条件を確認します。送料が未確認なら現金価格を確定扱いにせず、設定済みの送料予備額で仮計算します。
- **実店舗の現金購入：** ビックカメラ天神1号館・ヨドバシカメラ マルチメディア博多などの候補店について、正確な型番・色、店頭の税込現金価格、支店在庫または取り置き可否を確認します。全国向けのWeb価格から店頭価格を推定しません。
- **ネット注文・店舗受け取り：** オンライン注文価格・適用クーポン・店頭受取対象・対象支店の受け取り在庫を別々に検証します。店頭の現金価格とネット決済額は同じ値とは仮定しません。

スピーカー、サブモニター、ヘッドセットは購入対象外です。電源タップは所有済みなので購入・価格監視・予算計算に含めません。メインモニターは27インチWQHDを1台だけとします。

## 価格と送料の区分

- BF購入目標は希望値であり、実売・予測・注文可能価格ではありません。
- ネット商品ページの `current_price_jpy` はネット掲載価格です。店頭の `store_price_jpy` として流用しません。
- オンライン送料の `online_shipping_jpy` は決済画面等で実額が確認できた場合だけ入力し、`online_shipping_cost_verified=true` とします。未確認中は `online_shipping_reserve_jpy` を守りの予備額として使用しますが、実際の送料とは表示しません。
- クーポンは最終決済画面で適用を確認した場合のみ現金コストに反映します。ポイント、延長保証、同梱品等は現金支払額と分けます。
- ネット価格だけで「最安購入先確定」と表示しません。比較する店頭価格・店頭在庫が未確認なら、ネットが「確認できた候補の中で有効」と表現し、全ルート比較未完了と記録します。

## 店頭価格・在庫の記録項目（支店ごとに独立）

**支店ごとに価格・在庫を別のレコードとして記録します。** ビックカメラ天神1号館の価格とヨドバシ博多の在庫を組み合わせる、といった誤比較は禁止です。店舗ごとに同一型番・色、税込現金価格、在庫、確認時刻、証拠URLを保持します。

新しい記録先は config/targets.json の store_price_observations 配列です。1商品に複数支店のレコードを持たせられます。各レコードに必要な項目は次のとおりです。

- store_id: physical_store_candidate_ids 内の実在支店ID
- price_jpy: その支店の税込・現金支払価格（整数の円）
- price_basis: tax_inclusive_cash。ポイントを値引きとして差し引かない
- checked_at: 価格と在庫を確認したJST時刻。例 2026-11-20T14:35:00+09:00
- stock_status: in_stock / low_stock / out_of_stock / unknown / preorder_or_backorder
- confirmation_url: 該当支店の価格証拠となる公式HTTPSページ。同じ販売店ドメインであることを検証
- model_match: 完全な型番・色・容量・バリアントが一致した場合だけ true
- evidence_type: in_store_check / store_phone_confirmation / official_branch_price_page。official_branch_stock_page（在庫のみの証拠）は店頭価格の検証には使用不可
- evidence_notes: 確認した型番、税込現金価格、確認方法。ポイント・クーポンは別記

支店別在庫ページは価格を証明しないため、価格記録の evidence_type に指定できません。

従来の単一支店フィールドも後方互換のため受け付けますが、現金価格の基準を明示する store_price_basis = tax_inclusive_cash が必須です。出力のこれらの単一値は比較上の代表候補です。**支店ごとの判断・監査には store_price_observations 全件を使います。** 未確認の項目は空のままにし、価格を推測して埋めません。

**店舗受け取り用のWeb在庫表示は、店頭現金購入の棚在庫を証明しません。** 店頭現金価格とその時点の在庫は `store_price_observations` 内の同じ支店の確認記録だけで判定します。`store_inventory_observations` のWeb取置き/店舗受取在庫は別ルートの証拠として保持し、店頭現金価格の在庫を補完・上書きしません。

選び方は次のとおりです。まず、鮮度のある支店別在庫証拠がある価格だけを「購入可能な店頭候補」とします。その候補内で税込現金価格が最も安い支店を選びます。ポイント還元は現金値引きと区別し、対象者限定クーポンや会員価格は実際に適用できたことが分かるまで通常価格に反映しません。全支店の価格が未確認なら「店頭最安」や「全ルート最安」を確定しません。

## 店舗受け取り用の証拠

ネット注文の店舗受け取りは通常のネット配送/店頭現金購入と別ルートとして扱います。`config/targets.json` の候補商品に、実際の受け取り決済を確認した場合だけ次を記録します。

- `store_pickup_checkout_total_jpy`: 正確な型番・バリアントに対し、受け取り支店を選択した最終現金支払額。必須費用を含め、ポイントを現金値引きとして差し引かない。
- `store_pickup_quote_checked_at`: JSTの確認時刻。ネット販売ページの古い表示時刻や店頭在庫取得時刻で代用しない。
- `store_pickup_store_id`: 受け取り可能と確認した実店舗候補ID。
- `store_pickup_stock_status`: `in_stock` / `low_stock` / `out_of_stock` / `unknown`。
- `store_pickup_checkout_url`: ネットで注文・受け取り支店選択を確認した公式のHTTPS販売ページ。
- `store_pickup_model_match`: 正確な型番・色が一致した場合だけ `true`。
- `store_pickup_evidence_type`: `online_checkout_with_store_pickup` / `official_online_pickup_quote` / `store_pickup_checkout_screen`。
- `store_pickup_evidence_notes`: 型番、受け取り支店、最終支払額、必須費用、確認方法。

通常の商品ページ価格と支店在庫だけでは受け取り決済額の確定証拠になりません。これらの項目が揃わない間は、レポートに店舗受け取りルートの比較保留を明示します。

ネット商品ページしか確認できていない場合は店頭証拠項目を埋めません。同じシリーズの別型番、色違い、取り寄せ表示を店頭在庫ありとみなしません。

## 価格・在庫の有効期限

コードは確認時刻、支店ID、証拠種類、型番照合、公式支店URLを検証します。通常監視時の実店舗証拠は最大60分、BF監視時は最大30分の鮮度基準を適用します。期限超過、未来時刻、必要項目不足、支店不一致は有効な店頭価格/在庫として扱いません。

価格と在庫は別々の証拠です。価格が確認できても在庫が `unknown` なら購入可能とはみなしません。ネット配送は、商品価格・送料・販売元・在庫・返品条件を購入直前に再確認します。

## 自動監視の限界

`scripts/peripheral_monitor.py` は構成された商品ページURLを個別に取得して、正確な型番・価格・在庫状態を検証し、取得できたオンラインオファーの一覧と最安の有効候補を保存します。自動取得は最終カートの配送費、個人/会員別クーポン、実店舗の棚在庫、店頭現金価格を常に取得できるとは限りません。未取得は未確認とし、実購入時は人による最終決済確認を必須にします。

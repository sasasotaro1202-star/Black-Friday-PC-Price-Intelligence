# ChatGPTオンデマンド最終分析ガイド

この文書は、ChatGPTがユーザーからランキング・買い時・構成比較を依頼されたときの実行契約です。GitHub Actionsはデータ収集と品質検証、ChatGPTは収集された最新データと必要な外部調査に基づく最終回答を担当します。

## 役割の分担

- GitHubの自動生成ランキング、スコア、買い時レポートは**中間的な診断情報**であり、最終の買い物回答としてそのまま転記しません。
- 最新の価格・在庫・販売元・SKU・BF開催日程を読み、観測の鮮度、欠損、拒否理由、型番一致、PITを確認してからChatGPTが分析します。
- The final ranking is produced in ChatGPT only when the user asks.
- 最新データが古い、価格が直接確認できない、または店舗在庫が不明の場合は、その状態を明示します。推測して「確認済み」に変換しません。

## ランキング依頼時の必須出力契約

**ランキングを依頼されたら、必ず最初にデータの状態を報告します。** 確認時刻（JST）、各正本ファイルの生成時刻、対象候補数、現在価格・在庫の確認件数と未確認件数、公式2026年BF日程を確認できた店舗数、失敗・鮮度切れ・型番不一致の数を示します。データが揃っていない項目を「完全」と表現せず、証拠に基づく順位と暫定順位を分けます。

1. **最初に状態を示す。** 最終確認時刻、観測の鮮度、カバレッジと未解決項目を示す。
2. **候補別に価格の意味を分ける。** BF購入目標、BF前の参考価格、現在の有効な直接価格、BF期間内の確認済み価格、最終決済額を別々に表示する。
3. **PC構成を比較する。** CPU、GPU、RAM、SSD、マザーボード、PSU、ケース、冷却、OS、送料、小物、互換性を明記する。最低RAM 32GB・SSD 1TBを満たす完成構成だけを購入候補として扱う。
4. **予算計算は一貫させる。** PC計画枠35万円、周辺機器目標4.5万円、総額予備5,000円、総額上限40万円。予備費をPC目標や部品の価格に二重計上しない。
5. **周辺機器カテゴリも省略しない。** メインモニター、スピーカー、キーボード、マウス、マウスパッド、電源タップ、必要ケーブルを別々に比較する。サブモニターとヘッドセットは出さない。各カテゴリから選ぶのは1品だけで、代替品を同時購入した総額にしない。
6. **リスクを根拠に結びつける。** 「値上がりリスクが高い」は買う自動指示ではない。個別の価格履歴、供給/在庫、キャンペーン期間、目標との差を示し、根拠が不足すれば確率を出さない。
7. **大穴を含める。** RTX 5070 Ti 16GBやRTX 5060 Ti 16GBは比較から消さず、総額差、値下げ必要額、ローカルAI向けVRAMの利点、ゲーム性能とのトレードオフを示す。
8. **画像と購入リンクを添える。** 正確な型番が確認できる画像・商品ページを優先。画像は価格・在庫の証拠には使わない。架空のリンクを作らない。
9. **最後に買う/待つ/保留を示す。** 判断根拠、購入の条件、未解決の互換性・在庫・返品条件を短く明示する。

## 値上がりリスクに関する共通ルール

2026-10-17の監視優先はGPU → CPU → DDR5 RAM → SSD → その他パーツです。日本のGPU価格と米国Web価格の比較差は供給/価格リスクの警告材料ですが、正確なPNY型番の値上がり予測ではありません。AKIBA PC Hotlineの2026年10月前半調査ではRyzen 7 9700Xが¥51,800（前回比+29.6%）、9800X3Dが¥74,800（+24.7%）と報告されました。TrendForceは2026年第4四半期の契約価格をDRAM +10〜15%、NAND +15〜20%と予測していますが、契約価格の予測を消費者向けの特定RAM/SSDの店頭価格上昇率に置き換えません。

出典と意思決定ルールの詳細：[値上がりリスク・監視プレイブック](price-rise-risk-playbook.md)

## BF開催日程の厳密な扱い

- 暫定の広域監視窓：`2026-11-01 00:00 JST`〜`2026-12-11 23:59 JST`。
- これは価格収集用の監視窓であり、各店の公式開催日程ではありません。11月14日などを全店舗の開始日として推定しません。
- 「BF期間内の確認済み価格」と判定するには、その販売店の公式2026年キャンペーン日程、正確な商品・SKU、価格適用条件、在庫、取得時刻が確認できることが必須です。公式開催日程が未確認の店の価格は、たとえ安くても参考値として扱います。

## 最終判断のゲート

次のすべてを確認するまで、確定の購入推奨を出しません。

- [ ] 直接販売ページまたは店頭の同一SKUの税込現金価格が確認できている。
- [ ] 在庫または実際に予約可能な状態が確認できている。通信エラーを在庫切れ扱いにしていない。
- [ ] BF価格と呼ぶ場合、公式2026年キャンペーン期間内の観測である。
- [ ] RAM 32GB以上、SSD 1TB以上の完成構成になっている。
- [ ] CPU対応BIOS（現行ボード対象は9700X向け3.12）、正確なRAM QVL、GPUの寸法/電源/ケースクリアランスを確認した。
- [ ] 部品代、PC向け送料、必要な小物、OSライセンス、周辺機器を合計し、最終決済額と残予算を計算した。
- [ ] 返品条件・保証・納期を確認した。データが古い場合はそのことを明示した。

目標価格に届かない候補は値下げ必要額を示して監視継続にし、目標価格に届いても在庫・互換性・最終決済額が未確認なら保留します。

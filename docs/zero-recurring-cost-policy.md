# 継続課金なしを基本とする運用ポリシー

更新：2026-10-17（JST）

## 基本原則

このPCは、ゲーム、ゲーム制作、学校の勉強、Python/データ分析、スポーツ・株式・BTC予測、可能な範囲のローカルAIを長期間行うためのもの。**月額料金や従量課金を払い続けないと中核機能が動かない設計を避ける。**

- 基本は無料ソフト、オープンソース、ローカル実行、ユーザーが既に利用できる機能を使う。
- 月額AIサービス、有料API、クラウドGPU、有料データセット、サブスクリプション型の開発サービスは必須依存にしない。
- オンラインAIの無料枠は補助扱いとし、制限・仕様変更・提供終了が起きても基礎的な作業とデータ処理が止まらないようにする。
- 無料サービスのアカウント上限やAPI制限を無視した設計にしない。費用・上限が確認できないものは「未確認」とし、中核に入れない。
- ソフトのライセンス、商用利用、データ配布条件は用途ごとに確認する。無料であることだけで商用利用可能と判断しない。

## 初期セットアップの方針

- GitとGitHub、Python、仮想環境、エディタ、テスト、自動化スクリプトを無料で構成する。
- データ分析はNumPy、pandas、scikit-learn、Jupyterなどの無料ツールを基本候補にし、必要性が出た場合だけ他のツールを比較する。
- ゲーム制作はGodot、Unity、Unreal Engineなどを候補として、各エンジンのライセンス・収益条件・PC要件を開始時に確認する。特定エンジンの有料プランを前提にしない。
- AIや機械学習ではCPU/RAM/GPU VRAM/SSDのどこが制約かを測定し、GPUが全てのPython処理を速くするとは考えない。
- 無料で利用できる外部データがなくなる可能性を踏まえ、収集元・取得時刻・利用条件・失敗率を記録し、ソースを差し替えられる構造にする。

## 将来拡張の判断基準

PC本体やローカル環境を将来拡張することは許容する。ただし、月額料金を増やす前に、実際に観測されたボトルネックをもとに一回限りの投資を評価する。

1. まずCPU使用率、RAM使用量、VRAM使用量、SSD空き容量、温度、実行時間、失敗率を計測する。
2. ボトルネックに対応する部品のみを候補化し、互換性・電源容量・寸法・冷却・保証・総費用を確認する。
3. 初期PCランキングでは将来の増設を前提にしない。購入時点のメモリ32GB以上・SSD 1TB以上を守り、最初から64GB RAMや2TB SSDを搭載する方が合理的な場合は初期費用として比較する。
4. RAM、SSD、GPUその他のアップグレードは、必要な処理・作業が確認され、総合的に費用対効果がある場合に実施する。
5. 購入判断では、部品代だけでなく交換・互換性・電源・冷却まで含めた総額を比較する。

## 総予算との接続

- PC本体＋購入対象の周辺機器＋必要な付属品・送料＋総額予備費の合計を、絶対上限400,000円以内に収める。
- 現在の購入対象は、27インチWQHDメインモニター1台、キーボード、マウス、マウスパッド、必要な場合のみの不足ケーブル。**サブモニター、ヘッドセット、スピーカー、電源タップは購入対象外**とし、候補・価格監視・予算・ランキングに含めない。
- 周辺機器の約35,000円は計画配分であり、固定支出・使い切る目標ではない。PC側の送料・必要小物と総額予備費5,000円も含め、実際に必要な税込現金支払額からPC部品に使える上限を動的に計算する。
- 周辺機器が計画配分より安く済んでも差額を使い切る必要はない。余った額は総額の余裕として維持するか、実際に性能・作業性を改善するPC構成へ配分する。総額上限を超えるために対象外の商品を追加しない。
- ネット配送は送料・必須費用込みの現金支払額、実店舗購入は当該支店の税込現金価格と在庫、店舗受け取りはオンライン決済額と支店在庫を別々に確認する。ポイント還元を現金値引きと混同しない。
- BF購入目標、BF前の参考掲載価格、公式開催期間内に確認した価格、最終決済額を分ける。購入前に正確な型番、在庫、返品条件、保証、互換性を確認する。

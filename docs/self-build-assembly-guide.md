## まず結論

このプロジェクトの正式な購入方式は**自作PC**です。総額400,000円を絶対上限、PC本体の基準目標を360,000円、周辺機器の計画配分を約35,000円、総額予備費を5,000円とします。電源タップは所有済みのため購入・監視・予算計算から除外します。スピーカー、サブモニター、ヘッドセットも購入対象・候補・価格監視・予算計算から除外します。予算を使い切るためだけの購入はしません。GPU・RAM・SSD等で実際に性能や作業余裕を改善でき、最終価格と互換性が確認できる場合だけ上位構成を選びます。組み立て時間や作業時間は制約にも減点要素にも含めません。BTO完成品は比較ベンチマーク専用で、便利さだけでは自作本命を変更しません。最後はPC本体と必要な周辺機器の実費をもとに総額を最適化します。ネット配送は送料込み、実店舗購入は店頭現金額、店舗受け取りはオンライン決済額と支店在庫をそれぞれ確認します。

## 勉強・調査・データ分析も含めた用途評価

学習用のブラウザー複数タブ、PDF/資料閲覧、Web調査、動画教材、文書や発表資料の作成を無理なく行い、必要に応じてPython、Jupyter系の分析、GitHub、ローカルテスト、スポーツ・株式・BTC予測、自動化スクリプトやローカルAIを併用する想定です。

- 勉強・文書・ブラウザー中心の作業はGPUを最優先する用途ではありません。CPUの応答性、RAM、SSD、複数アプリの同時起動を重視します。
- 分析・予測はCPU処理、RAM、SSD I/O、GPU/VRAMのどれがボトルネックになるかを区別します。GPUがすべてのPythonコードや予測プログラムを自動的に加速するわけではありません。
- 無料・オープンソースを基本とし、有料APIやクラウドGPUを使わない場合でも利用できる構成を目指します。オンラインの無料枠は補助として扱い、必須の実行基盤にはしません。
- PC本体ランキングはFPSのみでなく、ゲーム制作、学習、分析、同時作業、冷却・騒音、総額40万円の購入条件をまとめて判断します。

## ゲーム制作を含めた用途評価

本構成は「ゲームを遊ぶPC」に限定せず、Unreal Engine 5 / Unity / Godotでの2D・3Dゲーム制作、FPS試作、街づくり・シミュレーション制作も優先用途に含めます。エンジンのエディター、IDE/デバッガー、プロジェクトのビルド、ブラウザー、テスト、Python/データ処理ツールを同時に使う想定です。

- **購入時の必須基準：** RAM 32GB以上、専用GPU VRAM 8GB以上、SSD 1TB以上。EpicのUE5公式推奨はRAM 32GB・グラフィックスメモリ8GB以上です。全エンジン共通の最低要件という意味ではありません。
- **予算が許す場合：** RAM 64GB、SSD 2TBを優先候補にします。これは大きなアセット、キャッシュ、複数IDE/ツール、ゲームビルドとAI/分析の併用に備える本プロジェクト上の推奨で、公式エンジン要件ではありません。価格と互換性を確認でき、購入時の全構成で総額に収まる場合だけ採用します。
- **GPUの役割：** RTX 5070 12GBを総合本命、RTX 5060 Ti 16GBをVRAM重視の代替、RTX 5070 Ti 16GBを性能重視の大穴とします。VRAM容量だけで描画速度やゲームFPSの優劣を決めません。
- **CPUの注意点：** Ryzen 7 9700Xは8コア/16スレッド。通常のゲームプロジェクト制作の計画土台ですが、Unreal Engine自体をソースからローカルでフルビルドする特殊用途では、Epicが示す12～16コアの実用目安を下回ります。そこが主目的なら、Ryzen 9などの多コアCPUを、実際のBF価格・他パーツ・40万円総額とあわせて別途評価します。
- **増設前提は禁止：** RAM/SSD容量は、購入後に増設すればよいとして候補を合格扱いしません。64GB/2TB案を提示する際は、該当容量を含む購入時の正確な型番・最終価格・互換性を照合します。

公式根拠：[Epic Games — Unreal Engine 5.8 ハードウェア/ソフトウェア要件](https://dev.epicgames.com/documentation/en-us/unreal-engine/hardware-and-software-specifications-for-unreal-engine)、[Unity 6 システム要件](https://docs.unity3d.com/6000.0/Documentation/Manual/system-requirements.html)。

## 組み立て手順

### 1. 作業前の準備

明るく乾いた、十分な広さのある机で作業します。金属製のケースに触れるなどして静電気を逃がし、可能なら静電気対策用品を使います。壁コンセントから電源ケーブルを抜き、作業中は通電させません。マザーボード、ケース、CPUクーラーの説明書を手元に置きます。

### 2. マザーボード上で取り付ける

1. CPUソケットの説明書を確認し、Ryzen 7 9700Xを向きの目印に合わせて置きます。**押し込まない・ソケットの接点に触れない**こと。
2. メモリはマザーボード説明書で指定された2枚構成のスロットに装着します。スロット位置を推測せず、説明書の推奨配置に従います。
3. M.2 SSDを指定スロットへ固定します。保護フィルムの有無とヒートシンクの取り付け方は説明書で確認します。
4. CPUクーラーをAM5用部品で取り付けます。付属グリスの有無を確認し、塗布量・固定順序・ファンの向きはクーラー説明書に従います。

### 3. ケースに組み込む

1. ケースのマザーボード用スペーサー位置がMicroATXの穴位置と合っているか確認します。不要な位置にスペーサーを残さないでください。
2. マザーボードを固定し、電源ユニットをケース説明書に従って取り付けます。
3. 24ピンのマザーボード電源、CPU補助電源、ケース前面スイッチ・USB・音声コネクタを、**各マニュアルの端子図どおり**に接続します。
4. GPUを最後に取り付け、固定ネジを締めます。電源端子は最後まで確実に挿入し、コネクタ根元で急角度に曲げたり、側板で圧迫したりしません。
5. ケーブルがケースファンに触れないよう整理し、工具・ネジなどが内部に残っていないことを確認します。

電源ユニット本体を分解しないでください。モジュラー電源のケーブルは、見た目が同じでも別電源のものを流用しません。コネクタが合わない、部品が抵抗なく収まらない、異臭・異音がある場合は通電をやめ、無理に進めないでください。

### 4. 初回起動とOS設定

1. PCを閉じる前に配線を確認します。モニターはまずGPU側の映像端子につなぎ、キーボードも接続します。
2. 初回起動でBIOS/UEFI画面を開き、CPU・32GBメモリ・SSDが認識されることを確認します。初回のメモリトレーニング中は、マザーボードの説明書に従って待ちます。
3. BIOS更新が必要なら、その型番の公式手順・対応バージョンを確認して実施します。更新中は絶対に電源を切りません。
4. まず標準設定で安定起動することを確かめてから、必要に応じてEXPOを有効にします。起動不安定なら設定を戻し、原因が特定できるまで追加のチューニングはしません。
5. 正規のWindows 11インストールメディアからOSを入れ、マザーボードのチップセット／ネットワークドライバー、GPUドライバー、Windows Updateを適用します。
6. CPU温度、GPU温度、ファン動作、メモリ容量、SSD容量、ネットワーク、音声、両モニター出力を確認し、負荷テストは温度・電源・冷却が正常と確認してから行います。

## 自作とBTOのどちらを買うか

自作は部品の品質・冷却・電源・GPU・メモリ構成を自分の用途に合わせられ、将来の交換も計画しやすい方式です。組み立て時間・作業時間はあなたの制約ではないため、比較時の減点や費用換算は**0**にします。故障切り分けとパーツごとの保証条件は、作業時間とは別の信頼性要因として記録します。

BTOは比較基準としてのみ残します。最終比較は「本体表示価格」ではなく、**同じ必須仕様（RAM 32GB以上、SSD 1TB以上）にそろえた総額**で行います。自作にはOS・送料・小物・必要なケーブルを加え、BTOには構成変更後の最終カート価格・送料を加えます。比較結果は自作部品の選定や目標価格の妥当性を判断する材料にしますが、組み立て不要という利便性で自作本命から切り替えません。

## 自作パーツごとの買い時判定

最新レポートには、自作本命のパーツごとに「BF購入目標」「確認済みの比較サイト参考価格」「目標までの差・必要値下げ率」「保存された参考履歴の最安値」「サンプル数」を表示します。取得済みの履歴が少ない場合は最安値や傾向を断定しません。

- 比較サイト参考価格が目標に届いても、それは購入店舗のBF実売・在庫・最終決済価格を意味しません。
- 検索スニペットだけの価格、型番が曖昧な価格、PIT条件不明の価格は、確認済みの現行価格や履歴最安として計算しません。
- パーツ別の「目標水準以下」「目標に近い」は参考値のアラートです。そのまま注文指示や「今買う」許可にはしません。
- 公式セール日程、対象SKU、販売店の在庫、送料込み決済価格、互換性、周辺機器込み総額が揃うまで購入許可は保留です。

## 自作での購入許可ルール

- BF購入目標額は目安にすぎません。確認済みBF実売価格として表示しません。
- 価格が欠落・古い・型番不一致の場合は0円で補完しません。
- 在庫取得失敗を売り切れと扱いません。
- 互換性がREVIEW／FAIL、OSライセンス不明、PC＋周辺機器の最終総額不明の場合は購入許可を出しません。
- 購入直前に、販売店の最終決済価格・在庫・送料・返品条件を再確認します。

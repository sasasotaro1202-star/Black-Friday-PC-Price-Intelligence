## 3. 価格変化をどう判定するか

1. **同じ型番を比較する。** 8GB/16GB違い、OC/非OC、長さ・厚さが違うGPU、同容量でも型番違いのSSD・メモリを同一SKUの履歴として結合しない。
2. **観測時刻と有効時刻を保存する。** `retrieval_time`、`available_at`、掲載/更新時刻、店舗、販売元、在庫状態、価格ソースを分離する。予測時刻より後で公開された情報を当時知っていたかのように使わない（PIT fail-closed）。
3. **単一観測で値上がり/値下がりを確定しない。** 有効で新しい履歴の複数点から変化方向を出し、サンプル数と観測窓を併記する。販売店をまたぐ比較では、販売元変更・送料・クーポン条件も区別する。
4. **現在価格・BF前参考価格・BF実売を分ける。** BF実売と呼ぶためには、該当ショップの公式2026年開催期間、正確なSKU、価格適用条件、在庫、取得時刻がすべて確認されていなければならない。
5. **クーポン・ポイントは分ける。** 適用対象、期限、併用条件、支払画面の現金決済額が未確認なら現金値引きに算入しない。
6. **取得失敗を売切れと解釈しない。** 403/404、タイムアウト、型番一致失敗、古い価格は別のステータスで記録し、根拠のないゼロ円や在庫ありに変換しない。
7. **リスク点数と確率を混同しない。** 優先順位は監視リソース配分に使う定性的指標。割引確率、売切れ確率、将来の価格を推定するには、同一SKUの十分な販売履歴・ショップキャンペーン履歴を別途必要とする。

## 4. 具体的な購入判断ルール

前倒し購入は、価格トリガーに到達した場合のみ再検討します。トリガー一覧と最終ゲートは[前倒し購入ポリシー](purchase-timing-policy.md)を参照。トリガー到達は購入許可を意味せず、直接価格・在庫・決済総額・返品条件・互換性・40万円総額を確認する必要があります。

### GPU・CPUを先に確認する

- GPUは価格差と在庫リスクの両方を観測し、CPUは直近の国内価格変化を踏まえて目標との差を優先確認する。ただし、この順序は「急いで注文する」命令ではない。
- exact SKU・直接販売ページの価格・在庫が確認できたら、PC本体の完成総額、電源、ケース寸法、冷却、マザーボードBIOS、RAMのQVL、SSD容量を再計算する。
- 価格がBF目標より高い場合は「目標差¥X／必要値下げ率Y%」を表示し、根拠のない値下がり確率は出さない。
- 価格が一時的に下がっても、販売元・SKU・在庫・返品条件が不明なら購入推奨にはしない。
- RTX 5070 Tiのような大穴はランキングに残し、必要値下げ幅と総額を明記する。目標を超えることと候補から削除することは別であり、購入許可は別ゲートで判断する。

### 総額ポリシー

- **総額の絶対上限は¥400,000。** PC本体の基準目標は¥360,000、周辺機器は計画配分約¥35,000、総額予備費は¥5,000。周辺機器枠は使い切る義務ではなく、実費からPC側の上限を動的に計算する。
- PC本体は自作を本命とし、PCパーツはネット購入を基本に送料・小物費を含める。BTO完成品は比較用ベンチマーク。
- 対象周辺機器は**27インチWQHDメインモニター1台、キーボード、マウス、マウスパッド**。付属ケーブルを確認し、不足品だけ買う。サブモニター、ヘッドセット、スピーカー、電源タップは購入対象外。
- 周辺機器は同一型番でネット配送・実店舗の税込現金購入・ネット注文の店頭受け取りを比較する。ネット配送は送料込み、実店舗は支店在庫と店頭現金価格、店頭受け取りはオンライン決済額と支店在庫を確認する。ポイントを現金値引きとして扱わない。
- PCは購入時点でRAM 32GB以上、SSD 1TB以上。購入後の増設を前提にしない。64GB RAM・2TB SSDは、その容量を含む完成構成が総額内に収まる場合のみ採用。
- 目標額の単純合算が¥400,000以内でも、現行の売り切れや在庫不明を含む場合は「購入可能総額」と呼ばない。最新の販売可能な直接価格・全必須部品の在庫・送料・決済条件・互換性を確認し、完成額を算出する。

## 5. 2026年BF日程の扱い

- 監視用の暫定広域窓は `2026-11-01 00:00 JST`～`2026-12-11 23:59 JST`。これは価格収集の期間であって、各店の公式開催日程ではない。
- 各店の公式開催日程を年付きで確認するまで、日付を推測しない。前年の開始日や曜日一致で2026年の日付を確定しない。
- 公式日程外の価格は、価格が安くても「BF期間内の確認済み価格」と表示しない。

## 7. 責任ある結論

2026-10-17現在、部品別の監視優先は **GPU → CPU → DDR5 RAM → SSD → その他の個別パーツ** です。これは現在の観測と市場予測に基づく監視順位であり、将来の値上がりが確定した順位ではありません。最終の買う/待つ判断は、依頼時点で最も新しい証拠を取得し、正確な型番・現金価格・在庫・キャンペーン適用・総額・互換性をそろえた後に行います。

# 無料サービス・課金防止ポリシー

監査日：2026-10-18（JST）

## 結論

**このプロジェクトの継続費用目標は月額0円。外部サービスの有料プラン、従量課金、従量課金API、自動チャージを中核に導入しない。** 無料条件が確認できない機能は使わず、「未確認」として保留する。

この文書は監査日時点の公式料金情報に基づく。料金・無料枠は変更されるため、新サービスを追加する前には公式料金ページを再確認する。

## 現在の運用判断

| サービス | 無料条件・制限（監査日時点） | プロジェクトでの扱い |
|---|---|---|
| GitHub Actions | **公開リポジトリの標準GitHub-hosted runnerは無料**。大規模runner等は対象外。公開設定を維持する | 使用可。現在確認した監視・テスト・watchdogワークフローは標準 `ubuntu-latest` を使用。大規模runnerへ変更しない |
| TickTick | 無料プランあり。公式料金ページではタスク・リマインダー等に無料枠がある一方、Premium機能と容量差がある | 任意の購入日リマインダーに限り無料プランを使用。Premiumへ加入しない。価格監視の技術的な依存先にはしない |
| TinyFish Search / Fetch | 公式料金ページではSearchとFetchに無料枠あり。Searchは30 requests/min・500 requests/hour、Fetchは150 URLs/min・1,000 URLs/day。Agentは1 stepあたり、Browserは1分あたりの従量課金 | Search/Fetchの無料枠だけが候補。Agent/Browserは有料なので自動処理に組み込まない。無料枠上限や規約が確認できない場合は利用しない |
| Firecrawl | 公式案内では月1,000 free credits、カード登録不要。追加クレジットの購入・従量課金設定は有料プランに関係する | リポジトリの必須依存にはしない。無料枠外の利用、課金プラン、クレジット自動追加は使わない |
| AWS Core / AWS Data Analytics | ChatGPTのコネクターを利用すること自体と、AWSアカウント上でリソースを実行することは別。AWSリソースは無料枠を超えると課金され得る | 現在はPC価格監視の実行基盤として使わない。AWSリソース作成、デプロイ、従量課金サービスの有効化をしない |
| Keepa API | 公式APIプランは月額課金・トークン制 | 導入しない。有料契約・API依存を追加しない |
| ChatGPTの検索・コネクター | アプリ内の利用制限やプラン条件に従う。開発者API利用料とは区別する | 最新情報の調査・手動分析の補助。外部API課金や無制限利用を前提にしない |

## 課金防止ルール

1. **新規サービスの追加前に、公式料金、無料枠、カード登録要否、無料枠超過時の挙動を確認する。** 1つでも不明なら導入しない。
2. クレジットカードの新規登録、無料トライアルからの有料移行、従量課金の有効化、自動チャージ、Walletへの入金、月額プラン契約を行わない。
3. GitHub Actionsは公開リポジトリの標準runnerに限定する。Private化・大規模runner・有料AIレビュー・従量課金APIを無断で組み込まない。
4. ワークフローでは既存の標準runnerとリポジトリ内スクリプトを基本とし、外部サービスAPIキーを必須にしない。秘密情報や決済情報をコード・ログ・レポートへ書き出さない。
5. 無料利用に必要なAPIキーがある場合でも、カード登録や有料枠が必要なら導入を見送る。キーが未設定でも基本的な監視・検証は動く構成を維持する。
6. 無料枠を超えた時は有料に切り替えず、取得頻度の調整、キャッシュ、公開ページの適切な取得、別の無料ソース、または「未確認」表示で対処する。
7. Web取得先の利用規約・アクセス制限を尊重する。403/404/429やタイムアウトを回避するために有料プロキシやスクレイピングサービスを自動追加しない。
8. 購入ランキングや価格監視の品質を改善するためでも、無断で有料サービスを追加しない。費用が0円と検証できない改善は保留する。

## GitHub Actionsの運用

- 公開リポジトリの標準GitHub-hosted runnerを使う。
- 価格コレクターは既存のBF監視窓設定に従い、通常時は低頻度、監視窓内は既定の高頻度で運用する。
- Watchdogの定期チェックは15分ごとにし、監視ワークフロー完了後の `workflow_run` 検査は維持する。監視自体のBF期間内スケジュールは変えない。
- 生成物やログを無制限に保存しない。大きなActions artifactや高価なrunnerを追加しない。
- 公開リポジトリをPrivateへ変更した場合は、Actionsの課金条件を再確認するまで高頻度スケジュールを見直す。

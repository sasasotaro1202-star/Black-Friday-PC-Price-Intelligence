# 周辺機器ランキング・購入計画（2026年ブラックフライデー）

更新日：2026-10-17（JST）。継続課金なしの運用方針：[docs/zero-recurring-cost-policy.md](zero-recurring-cost-policy.md)。総額上限は400,000円、PC本体の基準目標は360,000円。必須周辺機器の参考配分は約32,000円で、任意スピーカーを買う場合だけ8,000円を加えた約40,000円のシナリオにします。周辺機器予算は支出義務ではありません。PC本体に使える上限は総額400,000円から実際の周辺機器費と総額予備費5,000円を差し引いて動的に算出します。 スピーカーを選んで周辺機器費が約40,000円になった場合、本体の動的上限は予備費込みで355,000円が目安です。PC本体の基準目標360,000円をそのまま上乗せするのではなく、必ず実費ベースで総額を再計算します。

## 対象範囲と基本方針

購入するモニターは**27インチWQHDのメインモニター1台だけ**です。サブモニターは購入対象・商品候補・価格監視・予算・合計計算に含めません。ヘッドセットも購入対象外です。

**スピーカーは必須ではありません。** 不要なら買わずに標準予算・標準総額から除外します。スピーカーが必要だと判断した場合だけ、Creative Pebble Pro（BF目標¥8,000）などを比較します。EDIFIER MR3/MR4 MKIIは店頭試聴と価格差に価値がある場合のみ検討し、MR5は高価なため主候補にしません。節約分はPC本体に回すか未使用で残します。

PC本体はネット購入、自作を本命とします。周辺機器は福岡の実店舗購入を想定し、ビックカメラ天神1号館・ヨドバシカメラ マルチメディア博多を優先して店頭価格・在庫を確認します。周辺機器の送料は計上しません。Web価格・クーポン・ポイントは、店頭の税込現金価格を確認する前に実質値引きとして扱いません。

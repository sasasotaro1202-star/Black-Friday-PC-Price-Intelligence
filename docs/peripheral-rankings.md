# 周辺機器ランキング・購入計画（2026年ブラックフライデー）

更新日：2026-10-17（JST）。継続課金なしの運用方針：[docs/zero-recurring-cost-policy.md](zero-recurring-cost-policy.md)。総額上限は400,000円。周辺機器の参考配分は約40,000円で、45,000円固定ではありません。これは目安であり、必ず使う予算ではありません。PC本体に使える上限は総額400,000円から実際の周辺機器費と総額予備費5,000円を差し引いて動的に算出します。

## 対象範囲と基本方針

購入するモニターは**27インチWQHDのメインモニター1台だけ**です。サブモニターは購入対象・商品候補・価格監視・予算・合計計算に含めません。ヘッドセットも購入対象外です。

スピーカーは高級なモニタースピーカー級を必要としません。ゲーム、学校の動画教材、勉強、普段のPC音声が無理なく聞こえることを基準に、必要十分な製品をコスパで選びます。第一候補はCreative Pebble Pro、EDIFIER MR3は価格差に価値があると店頭で判断できる場合の代替です。MR4 MKIIは非常に割安な店頭価格のときだけ検討し、MR5は高価なため主候補にしません。

PC本体はネット購入、自作を本命とします。周辺機器は福岡の実店舗購入を想定し、ビックカメラ天神1号館・ヨドバシカメラ マルチメディア博多を優先して店頭価格・在庫を確認します。周辺機器の送料は計上しません。Web価格・クーポン・ポイントは、店頭の税込現金価格を確認する前に実質値引きとして扱いません。

### 購入直前チェック
- [ ] メインモニターは1台のみで、サブモニターは対象外になっている。
- [ ] スピーカーは必要十分な品質を満たし、音質のためだけに不要な追加予算を使っていない。
- [ ] 店頭の同一型番・税込現金価格・在庫を確認し、Web価格やポイントを店頭価格の証拠として扱っていない。
- [ ] 付属ケーブルを先に確認し、不足品だけ購入対象にした。
- [ ] PC本体＋全周辺機器＋PC側送料・必要小物＋総額予備費が400,000円以内であることを最終決済額で確認した。
- [ ] 周辺機器費は実費ベースで計算し、40,000円または45,000円を使い切る前提にしていない。

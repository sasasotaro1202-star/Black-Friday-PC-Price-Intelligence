# 周辺機器カテゴリ別ランキング（2026年BF購入目標）

更新日：2026-10-11（JST）

## 選定ルール

- 周辺機器はカテゴリ別に順位付けし、全商品を同時購入する前提にはしない。総予算37万円に入れるのは各カテゴリから選ぶ1商品だけ。
- BF購入目標と、10月に確認できた掲載価格を分ける。BF前価格をBFの実売価格として扱わない。
- 現金支払額、送料、確定クーポン、ポイント、商品価値を混同しない。ポイントは現金支払額を減らさない。
- 主画面は27インチWQHD・180Hz級、サブ画面は23.8インチFHDの作業用。ヘッドセットは購入対象外。
- 購入後のRAM/SSD増設は前提にしない。PC本体の完成構成と周辺機器を含めた合計を購入時に判定する。

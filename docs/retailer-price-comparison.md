# 自作PC部品の販売店別価格比較ルール

更新日：2026-10-18（JST）。

## 目的

価格比較サイトの参考価格だけではなく、Amazon.co.jp、楽天市場、Yahoo!ショッピング、ヨドバシカメラ、ビックカメラ、TSUKUMO、ドスパラ、パソコン工房、ソフマップ、Joshin、Arkなど、許可リストに含まれる販売店の**同一型番の直接商品ページ**を別々に比較する。候補販売先は固定せず、確認できた価格・在庫・URL・取得時刻を販売店ごとに保持する。

## 取得・比較方式

- 比較サイトのページ取得と、販売店の商品ページ検索を独立させる。比較サイトの価格が取れた場合でも、販売店調査を省略しない。比較サイトがタイムアウト・アクセス拒否になっても、直接販売店ページの取得を試す。
- 商品ごとに設定済みの直接販売店URLを調べる。加えて、許可リストから**1つの販売店検索ページを実行ごとに巡回**する。これは無料の監視を継続しながら、特定サイトへのアクセス集中を抑えるためである。検索結果のカード価格は候補発見専用とし、確定価格として扱わない。
- 検索で見つかったURLを直接再取得し、型番/商品識別情報・価格・在庫シグナル・取得時刻を検証する。型番やバリアントが一致しないページ、価格を商品に結びつけられないページ、許可リスト外へのリダイレクトは採用しない。
- 検索先を実行ごとに巡回するため、過去の実行で検証済みの販売店別掲載情報を、価格時刻の有効期限内は最新スナップショットに保持する。既定の掲載価格の鮮度上限は market_reference_max_age_minutes（既定360分）。これを超えた価格は比較候補として除外する。
- 在庫の有効期限は価格の有効期限と別に管理する。通常時の在庫シグナルは最大60分、設定した高頻度監視窓では最大30分。価格が6時間以内でも在庫確認が古ければ「現在購入可能」とは扱わない。
- 同じ商品ページに複数のマーケットプレイス販売者が現れる場合、データ取得元が販売者名を識別できれば別オファーとして扱う。ただし、ページ側が販売者別オファーを開示しない場合、Amazonなどの全マーケットプレイス出品者を網羅したとは主張しない。

## 価格の種類を混ぜない

| 項目 | 意味 | 購入可否の証拠としての扱い |
|---|---|---|
| 比較サイト参考価格 | 価格比較サイトで同一型番を識別して得た参考値 | 販売店の在庫・決済価格の証明にはならない |
| 販売店直接掲載価格 | 許可リスト内の直接商品ページから型番・価格を検証した掲載値 | 有効な在庫シグナルとURLが揃えば、販売可能掲載価格の候補 |
| BF購入目標価格 | 値下げを待つ判断に用いる希望値 | 実売価格・価格予測・セール確認済み価格ではない |
| 最終現金支払額 | 配送先/受取方法を選んだ決済画面で確認できた必須費用込みの額 | 注文直前に同じ構成・販売元・配送条件で再確認する |
| ポイント/特典 | 将来付与ポイント、ポイント倍率、特典など | 現金値引きとして差し引かず、現金支払額と別表示 |

ネット配送の総額は、同一商品の価格に送料・必須手数料を加え、決済画面で実際に適用を確認したクーポンだけを反映する。送料やクーポンが未確認なら最終現金支払額は未確認とする。会員条件、クーポン条件、販売元/発送元、配送先で結果が異なる可能性も表示する。

## 実店舗・受け取りの比較

ネット掲載価格、店頭の税込現金価格、ネット注文の店舗受け取り価格は別々に扱う。全国向けネット価格を店頭価格として転用しない。店頭価格は正確な支店・型番・色・税込現金価格の証拠を確認できた場合だけ記録する。店舗受け取りはオンライン注文に対象支店を指定した最終決済額と、その支店の受け取り在庫の両方を別に確認する。

## 出力上の制約

- レポートで示す「最安」は、取得時刻が有効で、型番が一致し、直接価格と販売可能在庫を確認できた**監視対象内の候補の中で**の最安を意味する。全インターネットの絶対最安を保証しない。
- 販売店直接掲載価格は最終カートの配送費、地域別制限、ユーザー別クーポン、会員条件、決済手数料などを必ず取得できるとは限らない。retailer_listing_reference_price_jpy は決済画面の確定額ではない。
- 一部の販売店がアクセス拒否・タイムアウト・JavaScript描画・価格非公開で取得できない場合は、その状態を「未確認」として保持する。最安比較の欠落を推定値で埋めない。
- 直接掲載価格、BF購入目標価格、公式BFキャンペーン開催日程、最終決済額はそれぞれ別の証拠レベルとする。購入前には型番・販売元・在庫・配送/受け取り方法・送料・クーポン・保証/返品・総額を再確認する。
- 無料の監視機能のみを使う。Keepa等の有料API、月額契約、従量課金の価格取得サービスを前提にしない。
